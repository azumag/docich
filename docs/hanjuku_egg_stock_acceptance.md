# 回復後の卵残数: 実戦受入条件

この文書は確認予定の条件であり、実施済みの報告ではない。

自然な半熟英雄runで、エンジェリン等の回復後に本人のステータスで残数5が実表示される場面を採取する。観測記録のrun identity・本人名・画像hash・判断IDを結び付け、直前の残数0が同じ本人について5に更新されたことを確認する。カードの選択記録だけから回復成功とはしない。

その後、同じ本人の戦闘で既存の緊急卵使用が適切に選択されるかを照合する。Aの計画と送信、召喚の結果は別々の証拠として扱う。実カーソル未読、既存のowner/lease/fresh-frame条件の未成立時には、今回の残数変更だけで確定を許してはならない。

費用面では、回復済みの本人を古い0回だけで再び回復対象にしないことを確認する。ただし別の卵・再確認要求・破損修理・賃金予備などの既存予約をまとめて消してはならない。月初回復の通常4回目標、一回型の1回目標を維持する。

受入のために実行中の試合を停止・リセットしたり、共通配信基盤を再起動したりしない。未観測のケースは未確認と記録する。CI成功は、実ゲームでの回復発動・入力送信・勝率向上を証明しない。
