# 確実に倒せる自動選択で高火力札を温存する

## 目的

救命時の実在札選択や、実行できないチャート札からの自動再選択で、確実に敵を倒せる札が複数ある場合に必要十分な火力を選ぶ。キャトルミュー等を固定順位だけで使い、より小さな一撃で終わる戦闘に高火力札を消費することを避ける。

この方針は資源配分の改善仮説であり、攻略サイトがこのbotの最適な選択順や勝率向上を保証するものではない。

## 攻略資料と既存推定器

2026-10-09確認。

- [GCGX 切り札](https://gcgx.games/hanjuku/kirihuda.html): 相手種別ごとの基本ダメージ、自軍兵士による加算、回復などの固有効果。
- [RRPG 切り札](https://rrpg.jp/hanjuku_hero_2/trump.html): 将軍・エッグモンスター・ボスの効果の区別と補助照合。
- [GCGX 戦闘](https://gcgx.games/hanjuku/battle.html): 通常兵士1人のHP10。

選択は既存 `card_damage_estimate` と `_card_damage_gate` の結果をそのまま使う。兵士の吸収、敵将軍ボスの兵士HP、ボス用ダメージ列、未知兵数の安全側計算を変えない。札を選んだ回数から、兵士HP半減や敵HP低下を推測しない。

## 判断順

1. 既存の回復が必要という判断があればエンジェリンを優先する。
2. `single_card_lethal` と認められた自動選択候補の中だけで温存を検討する。将軍HPが既存の危険閾値12以下、または不明なら従来の救命順位を維持する。
3. HPが12を超え、数値のダメージ下限と自傷なしが既存推定器で確認できる候補から、兵士吸収前の `raw_damage_min` が最小の札を選ぶ。同じ敵・同じ兵士吸収量に対する比較なので、確実性を下げずに過剰な火力を抑える。同値は既存の救命順位・卵落適性を維持する。
4. その条件を比較できない時、単発撃破が未保証の時、敵召喚中の時は、既存の回復・卵落・連携などの順位へ戻す。

価格や希少性を数値化した最適化ではない。回復効果、将来の遭遇、操作遅延を含む最適資源配分の保証もしない。

## 維持する境界

- 実一覧にないチャート上の札を候補へ追加しない。
- 有効なチャートが明示指定した札の選択を置き換えない。変更は既存の自動選択関数内だけ。
- 現在のカーソルが選択札を指さなければAを返さない。一覧・HP・兵数が更新された場合は既存の最終ゲートで再評価する。
- ナビゲーション回数、保留時間、退却、卵使用、戦闘終了の条件は変更しない。
- `cards_selected` と `cards_used` は別。選択予定は送信・消費・命中・撃破の証拠ではない。

## 検証と実戦受入

`tests/test_hanjuku_finisher_conservation.py` は合成パネルで、救命/チャート再選択の両経路、兵士吸収後の単発撃破境界、未知兵数、危険HP・回復優先、明示チャート維持、一覧にない札の拒否、次画面での再評価、カーソル未読を確認する。最終PRへテスト実行結果を記録する。

自然なrunで、実一覧に複数の撃破可能札があり、低火力札を選び高火力札を残せたかを判断・送信・結果の別々の証拠で照合する。これは未実施の受入条件であり、実戦勝率・実入力・本番反映を確認済みとは扱わない。受入のためのゲーム/配信の強制再起動・リセットは行わない。
