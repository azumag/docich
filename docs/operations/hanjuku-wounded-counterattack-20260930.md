# g508の消耗とv102

ユーザー指摘の将軍不足はv95以降、観測上6人未満なら募集費50Gを兵士より先に予約する。
死亡人数を在城一覧の欠落から断定しない。g508の1-6では兵士0、
募集費127→77の領収、クミンの実加入告知1790754236.7714486、
メニュー復帰69Gを確認。追加8Gの原因、具体配置は未確認。
セルリアクはその後キカンドン防衛0対バジル17で敗北。増員だけでは消耗を止められない。
1-7はトレビス加入告知1790754823.6015186/396→346領収/338G復帰、城status66も確認。
しかし1-8 166Gの最初のメニュー観測1790755241.221509ではmenu_toがNoneとなり募集を即skip。
予約50Gを残したまま兵士86人を補充し、募集だけが抜けた。単一の不完全表示から見送りを確定した退行。
v102は募集優先時の欄/カーソル欠落を6観測待ち、読めたら兵士前に募集する。
7観測目まで欠落する場合はunverifiedとして終了し、募集費は維持、無限待機しない。

16:34のヴィーナス対カシュー/カストーラはエクスカリバー299召喚後、敵ダークエルフ240。
既存のマサムネる4連続を選択したが味方召喚獣を失った。卵行不能、退却復帰B3回でも
通常コマンドに戻れず、こうげきを繰り返して本人0/敵将軍29で敗北。
死亡は未分類、現ランゲームオーバーはこの時点では未観測。
固定frame036のRGB 232a183fd4ea57828eb88540f3f1b429d86d6f0e82a2383cdc94e0a50d97b546は
1790753591.2442434の観測と一致。本人82/ダークエルフ216、敵HP行y212。
旧認識範囲y216まででは下段文字を切り落とし、敵パネルを取得できなかった。
後のframe040/044はリング上書きでRGB不一致のため実負傷HP証拠には使わない。

v102は下段認識をy224まで延長し、実味方行が当該将軍と一意に一致する場合だけHPを更新する。
味方召喚獣HP・敵召喚獣HPを将軍HPへ代入しない。最大HPは既知一般将軍値/実主人公最大値。
卵行不能・予定未試行札なし、実既知敵召喚獣が生存し、本人0超かつ最大HP半分以下の場合に限り
もうこうげきへ移動する。攻撃戦の有限退却B3回・防衛退却禁止・実レア札・原典札戦術を維持。
実ラベルと手/騎士カーソルで移動し、HP回復等で条件外になればこうげきへ戻す。
もうこうげき選択中のカーソル欠落では盲目的なAを押さない。

[仕様](https://wikiwiki.jp/hjksfc/%E5%B0%86%E8%BB%8D)は最大HPと現HPの差をダメージへ加算。
[基本情報](https://w.atwiki.jp/gameguidesite/pages/28.html)の上下技の先手差も考慮する。
命中/先手の不利があり、確殺やこの過去戦の救済を保証しない。自然勝利は未確認。
実固定画像で両パネル/騎士/通常攻撃を再現、負傷分岐は合成パネルで回帰検証する。
