# #5381: 非ボス城の敵召喚獣戦でも携行札行を探索する

## 症状と原因

2026-11-24 の ch4 6-7 で、携行が確認されたクースカンを残したまま、敵召喚獣戦の「こうげき」へ進んだ。既存のスクロール条件は「たまごをつかう」行の可視性または卵0の確定を要求していたため、灰色の卵行がOCRから欠落し、卵残数も未確定の画面では下段の「きりふだ」行を探索しなかった。

従来のボス城限定fallbackは、ch4の候補出撃先が非ボス城である可能性を排除できず、本件を確実にカバーしない。

## 修正（v1460）

次の証拠が同時に揃う場合に限り、下方向入力を表示探索として許可する。

- 現在の味方将軍HPパネルを一意に読める
- 出撃側の戦闘である
- 敵側に認識済み召喚獣がちょうど1体いる
- 現在画面に「こうげき」がある
- 未使用の確定携行札がある

城がボス城かどうかは条件にしない。敵不明・複数敵・味方パネル不明・防衛側ではfallbackしない。下方向入力は行の表示探索だけで、実際のカード選択は新しい画面で「きりふだ」行を読み取ってから行う。既存のスクロール上限とcard_flowガードを維持する。

## 回帰テスト

- 非ボス城・卵行OCR欠落・既知の敵召喚獣1体・味方攻撃メニューでは下方向のみ送る
- 未分類の敵ではfallbackしない
- 防衛側ではfallbackしない
- 既存のボス城・卵行可視/卵0・カード再開テストを維持する

## 受入

CIでfocused tests、Full-suite、Prediction、Recovered egg、Retro、VM operations/securityを確認する。runtime受入は別途、非ボス城の召喚獣戦でスクロール後に実際の携行札行を読み、正しい札を選択したことを確認する。
