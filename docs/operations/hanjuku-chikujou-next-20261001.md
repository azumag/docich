# 築城不可の城から次候補へ進む

ユーザーはアルマムーンが「これいじょうのぞうちくはできませんぞ」と表示しても他城を選ばず終了することを観測した。既存実装は本城を先頭にし、当該文言で築城全体を終了していた。

v112は選択済みの城で拒否を観測した場合だけ、その城を今回の候補から除外し、既存駐留記録のある次の城を探す。拒否は月内制限の場合もあるため永久レベル上限とは断定しない。候補不足・選択文脈欠落ならBで終了。前の拒否文言が入力後も残る場合、新しい候補への拒否と誤認せず最大6観測で閉じる。

成功後は従来通り当月の築城を終了する。賃金・募集・主人公の卵修復の予算保護は維持。支払いの見積もりは拒否時に破棄し、次の実確認画面から再取得する。築城の複数城連続成功・前線優先度の再設計はこの変更に含めない。
