# Yジャンプ上限を2つの保管先で保持する（v427、2026-11-05）

## 背景

v426 で Yジャンプの総量上限を入れたところ、**実測で効果を確認できました**。

- v425: 9.1分で `y_jump_open` **63件**（約7件/分）
- v426: 8.5分で **1件**（約0.1件/分）

同時に `chart_adjust_applied` も 63件 → 1件 に減り、計画の再構築ループも止まりました。

## 変更

- 上限の判定を2つの保管先で行う: `tally`（この実行では残ることが確認できた）と
  `y_jumps_total`（素の辞書。再読み込みで残る側）。どちらかが上限に達したら止める。
- `_start_y_jump` は両方に加算する。

## 検証

- `tests/test_hanjuku_yjump_budget.py` を3件に更新（辞書だけで止まる／tallyだけで止まる／
  開始時に両方へ加算）。
- 関連（`off_chart` / `chart_bot` / 層）427 passed。
