# 半熟英雄: ボス戦で卵の行が灰色なら召喚不能として記録する（v562、2026-11-09）

## 症状

g1163 第6話 2026-11-09 13:36:33 JST。ヘーゼルがボス（ハードロボ HP152）へ突入しましたが、
召喚戦メニューで「たまごをつかうが使えない」表示 → こうげき で応戦 → 約1分半で敗走。
**ボスHPは152のまま**（1点も削れず）。その後も同じ将軍が波に再利用されていました。

卵の状態（`egg_uses` / `egg_types`）は多くの将軍で未読のため、
`_boss_egg_rank`（v558）は「不明=1」としか判定できず、召喚できない将軍を避けられません。

## 修正（v562 `hanjuku-chart-v562-boss-egg-unusable`）

`egg_battle_step` の「たまごをつかうが使えない」経路で、**ボス城の戦闘に限り**、
その将軍を召喚不能として `egg_uses[general] = 0` に記録し、
`egg_unusable_recorded` を残します。

- `_boss_egg_rank` は uses<=0 を「2（破損・使用済み）」と判定するため、以後のボス波で
  優先度が下がります。
- 通常城の戦闘では記録しません（灰色の理由が別にある可能性があるため）。
- すでに 0 の場合は重複記録しません。

## 確認

- `tests/test_hanjuku_boss_egg_unusable.py`（新規2件）: ボス戦の灰色行で記録、
  通常城では記録しない。
- 卵・ボス波・ボスHP 79件 passed。
- 本番反映後: 召喚できない将軍がボス波から外れ、ボスHPが実際に減ることを実測する。
