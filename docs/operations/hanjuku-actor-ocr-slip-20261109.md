# 半熟英雄: 出撃画面の将軍名1文字読み違いを本人として扱う（v603、2026-11-10 オーナー報告）

## 指摘（オーナー）

「ポセイドンの直近の出撃がずっとキャンセルされてる」

## 実測

01:09:25〜01:30:18 に **`sortie_actor_unconfirmed` が11件、すべて ポセイドン**。
`observed` は **「ホセイドン」** または **「ポ??ドン」**（`?` は読めなかった文字）。

つまり**出撃画面の将軍名の1文字（ポ→ホ）または2文字が読み取れないだけ**で、
「予定の将軍と違う」と判定して3回で出撃を取り消していました。

## 修正（v603 `hanjuku-chart-v603-actor-ocr-slip`）

`_actor_name_slip(observed, selected)` を追加し、次のすべてを満たすとき
**読み違いとして本人とみなし承認**します（`sortie_actor_ocr_slip` を記録）。

- 文字数が同じ
- 観測名が**実在の将軍ではない**（参照表に無い＝読み違いの疑い）
- 読めた文字が3文字以上あり、**不一致が1文字以内**

「ゼウス」のような実在の別将軍や、無関係な名前は従来どおり取り消し。
