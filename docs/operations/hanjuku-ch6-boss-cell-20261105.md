# 第6話のボス城に座標がなく章末で攻撃できない（v395、2026-11-05）

## 症状

第6話で全通常城を制圧すると、ボス（完熟秘密基地）への攻撃指示が作られず、
フィールドで何もすることがなくなる。

g1133 の実測（2026-11-05 02:00 JST、12城すべて自軍の状態を再現）:

    next_order(mem) -> None
    interim_candidates(mem) -> {}

ボスが候補に入らないため、章を終えられない。

## 原因

- `chart.castles(6)` は通常城12件だけで、ボス城 `ボス` のセルを持たない
  （第1・2・3・5話は持つ。第4話は四季王の4地点、第9話は移動ボス）。
- 機械計画のボス波は `if boss in castles ...` で候補に追加するため、
  セルの無い第6話では一度も発火しない。
- 第6話のボスは「全ての城を制圧すると出現する」ため、通常城の座標表
  （公開資料の旗位置）にも載っていない。

## 修正（v395）

- 第6話の `ボス` にセル `(818, 184)` を追加する（`SECRET_BASE_CELLS`）。
  根拠: GCGX 06 の「全ての城を制圧すると完熟秘密基地が出現する」と、
  ファン掲示板の「マップ右上の森の中心部に出現する」。g1133 の 22:23 の
  Y 画面で右上の森の中心を (166.5, 68.0) と測り、第6話のオフセット
  (64.3, 45.0) から `8 * (166.5 - 64.3, 68.0 - 45.0) = (818, 184)`。
- これは近似の初期位置。城の屋根確認（`_hold_off_castle`）と内陸探索が
  入城を守るため、位置がずれても誤って攻撃はしない。実測が取れたら置き換える。
- ボスは通常城の目標一覧から除外され、全通常城が自軍になった時だけ候補に
  入る（既存の `chain_held` 条件）。

## 確認の仕方

- `chart.castles(6)` に `ボス` が入り、全通常城が自軍のとき
  `interim_candidates` に `target=ボス` の攻撃が現れること。
- 通常城が1つでも敵のときは現れないこと。
- `tests/test_hanjuku_boss_wave_double.py` の第6話テストが上記2点を確認する。
- 実プレイでは、全城制圧後にボスへ出撃し、屋根確認で入城できるかを実測する。
  位置がずれる場合は `arrival_unverified` が残るので、その画面から再測定する。

## 未確認

- (818, 184) は外部資料と Y 画面からの推定で、実機の城屋根では未確認。
- 第7話以降のボスも同様に座標が無い（`castles(7..12)` にボス無し）。同じ
  症状が章末で起きるため、各話で実測して追加する必要がある。
