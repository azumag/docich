# 半熟英雄: 価格表に無いカード名でも切り札一覧を読む（v613、2026-11-10）

## 症状（実測 04:52）

「切り札一覧の名前・数量・配置またはカーソルが実測構造と一致しないため保留」が
5回続いた後、出撃が取り消されました。**画面の文字は読めていました**（`text_len: 103`）。

読み取れた内容:

```
136,31 きりふだセレクト   208,31 あと3こ
160,55 ダイチスイム 8     160,71 ブラッキー 12
160,87 フットバース 8     160,103 ゲンゴナイト 9
```

## 原因

`_measured_card_select` は各行の名前が `ALL_CARD_NAMES`（参照29＋卵系3＝32枚）に
含まれることを要求していました。**ゲンゴナイト／ライチスイムは価格表に無い**ため、
1行でも混ざると**パネル全体が読めない**と判定され、保留→取消になっていました。

## 修正（v613 `hanjuku-chart-v613-card-name-table`）

- `EXTRA_CARD_NAMES = {'ゲンゴナイト','ライチスイム'}` を追加し、
  `ALL_CARD_NAMES = 参照32枚 ∪ EXTRA` としました。
- **選択対象にはなりません**（選択は `CARD_IDS` の価格付き集合から）。ID計算も不変。
