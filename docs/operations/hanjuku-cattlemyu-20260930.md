# レアイベント札キャトルミューの活用

ユーザーがg496の火星人襲来とキャトルミュー5個の取得を報告した。
現取得ログは汎用イベント文章を記録しておらず、現policy.card_stockにも未掲載。
報告を取得の根拠として受け取るが、botが在庫5を観測したとは記録しない。
RRPGの切り札表 https://rrpg.jp/hanjuku_hero_2/trump.html とイベント表
https://rrpg.jp/hanjuku_hero_2/event.html で効果・取得経路を照合。
通常将軍は一撃、EMへ224ダメージと石化、ボスへ90ダメージ。

従来はALL_CARD_NAMESで在庫行を読めてもCARD_NAMESに無く、出撃確認・
戦闘選択・調整チャートでは利用できなかった。v93はこれらの対象へ追加する。
店に無いイベント限定札なのでpurchasesへは追加を拒否し、調整AIへも明示する。

月に一度（章開始の月不明期間も一度）、未選択の出撃在庫を最大32回の下入力で探索する。途中/隠れた4行から
不在を断定せず、末尾または上限では1観測1入力で巻き戻し通常選択へ戻る。
実在庫が正数・携行余枠あり・まだ何も選んでいない時だけ1枚を優先し、
他の札は原順序でID合計47以下・最大3枚へ収める。ID28の2枚持ちは56のため避ける。
確認済み携行札だけを戦闘へ結び付け、選択済み未分類使用は既存のkit_spentで
再使用を抑止。通常将軍では開幕、ボス行軍中は温存し実ボス突入後に使用。
EM召喚戦では一度通常コマンドへ戻り、実携行札を選ぶ。既存の回復/緊急退却は維持。
レア札なしの原典チャートは維持し、レア札変更はrare_cattlemyuとして区別する。
章/出撃の再試行では探索/kitの古い状態を破棄する。

最終半熟全体1175 passed / 1 skipped / 1 deselected成功。
除外は未初期化submoduleの実知識検査のみ。専用18件と既存選択契約を含む
局所166件成功。月不明探索で旧テストの前提が変わったCI失敗を調査し、
0枠で探索する退行を修正、選択契約は探索済み状態を明示、新結合テストで
探索前→在庫5実測→選択予定の経路を検証。探索/巻き戻しの入力記録も追加。
