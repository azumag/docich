# 半熟英雄: 直近に攻められた前線は最強の将軍を防衛に残す（v771、2026-11-13）

## 症状（実測 g1163 2026-11-13 15:3x〜16:1x）

`オオキク` / `ドンドン` の防衛戦が、**enemy HP 1〜8 の僅差**で繰り返し
敗れていました。

```
15:35 オオキク ally 66 → 0, enemy 76 → 2   lost
15:53 オオキク ally 55 → 0, enemy 76 → 5   lost
14:46 オオキク ally 0, enemy 36 → 3        lost
```

v762 で「攻撃の先頭は元気な中で最大HPの将軍」にしたため、**最も強い将軍が
攻撃に出て、防衛に残るのは次点以下**になっていました。敵の反撃はその
弱い防衛将軍に当たり、僅差で落としていました。

## 修正（v771 `hanjuku-chart-v771-keep-defender`）

出撃元が `defense_seen`（直近にせめこまれた）の窓内にあるとき、
攻撃の先頭を**元気な将軍の2番目**にします。最強の将軍は城に残ります。

- 防衛記録が無い前線は従来どおり最強（v762）が先頭。
- 元気な将軍が1人しかいない場合はその1人（従来どおり）。
- 防衛窓は 900 tick（corridor の `_defended_recently` と同じ）。

- `defense_seen` のある城からの攻撃で `full_hp_leader.chosen` が2番目になること。
- 防衛戦で最強の将軍が城に残り、enemy 1〜8 HP の僅差負けが減ること。
- 防衛記録の無い攻撃は従来どおり最強が先頭であること。
