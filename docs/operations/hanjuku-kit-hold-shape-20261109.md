# 半熟英雄: 携行切り札の保留に「何枚/何枚」を残す（v622、2026-11-10）

## 背景（実測）

`sortie_confirm` の「携行切り札の読取が不確実または計画と不一致のため出撃承認を保留」が
**1時間で21件**。上限（8回）到達で「読めた携行札が真実」として承認されるまで待つため、
1出撃あたりの待ちが長くなっています。

## 変更（v622 `hanjuku-chart-v622-kit-hold-shape`）

保留レコードの `hold_variant` に内訳を残します。

- `kit_mismatch:<実際の枚数>/<計画の枚数>`（読めているが違う）
- `kit_unreadable`（読めていない）

## 理由

「読めない」と「読めたが違う」は対処が異なります（前者は盲承認、後者は計画側の札選び）。
現状は同じ文言で区別できず、上限短縮の可否を判断できませんでした。次段で
`kit_mismatch` が多いなら計画の札選び（在庫に無い札を計画している）を直します。
