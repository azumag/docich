# 半熟英雄: 野営探索の記録を月内位置つきで増やす（v811、2026-11-14）

## 症状

v810 の `camp_hunt` は300 tick に1回で、月のどのあたりの地図フレームかを
残していませんでした。月の長さが 120〜300 tick と短いため、300 tick 間隔では
1か月に1回も残らず、月次処理と遷移に対する地図フレームの分布を測れません
でした。

## 修正（v811 `hanjuku-chart-v811-hunt-timing`）

- 記録間隔を 300 → **100 tick** に短縮。
- `month_elapsed`（月の開始からの経過 tick）を追加。

挙動は不変更（入力もしない）。

## 検証

- 既存の `test_an_empty_field_records_a_throttled_hunt_sample` を拡張:
  100 tick 間隔で記録され、month_elapsed が入る。
- 野営・帰還・月場面・field recall 関連の既存テストを実行。
- 修正前の `recall.py` では新テストが失敗することを確認。

## 本番反映後に実測すること

- 月の前半・遷移前・遷移中に地図フレームがどれだけ来ているかを
  `camp_hunt` の month_elapsed で確認できること。
- その分布から、野営を拾うべきタイミング（カメラ誘導・探索）を決めること。
- 12話ボス撃破には未到達。目標は active のまま継続します。
