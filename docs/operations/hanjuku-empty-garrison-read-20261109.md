# 半熟英雄: 1回の空読み取りで城を「将軍なし」にしない（v542、2026-11-09）

## 症状

g1163 第6話 2026-11-09 08:31:26 JST。出撃元 アルマムーン の将軍一覧の読み取りが
`garrison_seen {}` として**空の在城**を記録しました。実際には
どうし・アルファルファ・ジェラート が在城していました（直後の出撃で確認）。

空の在城を記録すると、その城は「将軍なし」とみなされ、出撃元・守備将軍の判定から
外れます。

## 原因

`_observe_garrison` は一覧の読み取り結果が空リストだと、遷移フレームやOCRの取りこぼしでも
そのまま `garrison[castle] = []` として記録していました。

## 修正（v542 `hanjuku-chart-v542-empty-garrison-read`）

- ゲーム自身の「将軍なし」表示（`おりません`）を含む画面は、1回で空の在城として記録。
- それ以外の空読み取りは**2回連続**（`GARRISON_EMPTY_READINGS`）で初めて記録。
  1回目は記録せず、名前が読めた時点で連続カウントを破棄。
- 従来どおり、読み取り不能（`None`）は記録しない。

## 確認

- `tests/test_hanjuku_off_chart.py` に1件追加: 空読み1回では記録しない、2回で記録、
  「おりません」は1回で記録、名前が読めたら即時更新して連続カウントを破棄。
- 出撃・在城・チャート 474件 passed。
- 本番反映後: `garrison_seen {}` の誤記録が消え、在城将軍が正しく残ることを実測する。
