# 半熟英雄: 待ち伏せ将軍の実位置を記録する（v1277、2026-11-21）

## オーナー指摘

「そもそも全然軌道上に配置できてないよ。9話のボスの軌道と、どれくらいで
一周するかは、ROMを解析してください」

## 現状の切り分け

- これまでは `ambush_cell`（狙った軌道セル）しか記録しておらず、
  **将軍が実際にそのセルに居るか**を測っていなかった。配置の成否を
  「狙い」と「実位置」で分けて観測できるようにする。
- ROMの静的解析: 1MBのROM内に、実測セル（例 `[818,853]` `[874,229]`）の
  16bit/8bit座標ペア・テーブルは見つからず、座標列は単純な表ではなく
  コード側の移動処理で持たれている可能性が高い（座標系も view px / field px /
  tile のいずれか未確定）。静的抽出だけで軌道を確定するのは現時点では
  できていない。実測トラック（16点）では南 y≈629〜853 と北 y≈173〜373 を
  往復し、南→南の間隔は約3050 tick（≒50分）と読める。
