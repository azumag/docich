# 現在地の推定が固まったら内陸サーチを始める（v430、2026-11-05）

## 症状（実測）

policy の `cursor` が **[392,144] のまま数時間**、`nav_last` は null、`uncertain` は true。
25秒おきに6回サンプルしても1ピクセルも動いていませんでした。

- `update_world` は位置が確定していない間、推定を凍結します（設計どおり）。
- 凍結を解くには屋根アンカーが要りますが、その屋根が見えない場所にいるため再特定できません。
- コードには「城の多い内陸へ動いて屋根アンカーで再特定する」`nav_search` がありますが、
  起動条件が「出撃元に着いたのに屋根が無い」経路だけで、**凍結した推定では到達しませんでした**。

## 変更

- `flows/map._watch_cursor_still(mem)` を追加し、`map_step` の冒頭で呼ぶ。
- `cursor` が `CURSOR_STILL_LIMIT`（40観測）連続で同じなら `nav_search` を立て、
  内陸へ動いて屋根アンカーで再特定する（`cursor_still_search` を記録）。
- 位置が動けばカウントはリセットされ、`nav_search` が既に立っていれば何もしない。
