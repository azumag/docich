# 半熟英雄: 一撃フィニッシュは敵兵士ゼロが条件（v1341、2026-11-22）

## オーナー指摘

> one hit lethal ですが、ボスだからじゃなくて、ボス兵士が残ってるからHPが削れないんだよ

そのとおりで、敵将軍のHPが1でも**敵の兵士が残っていれば押し切れず**、
白兵では勝てません。ボス固有の話ではありませんでした。

## 症状（本番 g1288 実測）

```
23:35:46 シャルドネ   vs せいめいたい  hp 56 / 敵1 → loss
00:32:45 ローズマリー vs せいめいたい  hp 98 / 敵1 → loss
00:33:33 マンゴスチン vs せいめいたい  hp 85 / 敵1 → loss
```
いずれも `battle_one_hit_finish`（敵HPが一撃値なので白兵）を選び敗北。
敵将軍HP1でも兵士が残っていたため、HPを削れませんでした。

## 変更

- `judgment/battle._one_hit_lethal`: **`cur['enemy_soldiers'] == 0` を必須**に。
  兵士が読めない（None）場合も一撃とは扱わない。
- `tests/test_hanjuku_one_hit_finish.py`: 合成パネルに `field_soldiers=(90, 0)` を
  明示し、兵士>0 / 未読 / 0 の3ケースを追加。
- `BOT_VERSION` v1341、hot-load許可リストへ追加。
