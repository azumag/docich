# 半熟英雄: 切り札スクロールの「まとめ送り」をタップ連打へ直す（v552、2026-11-09）

## 背景

v551（PR #3788）で切り札一覧のスクロールを `pad(direction, frames)`（押しっぱなし）で
まとめて送る実装にしましたが、実機では**1回のホールドで1行しか動きませんでした**。

- 11:46:26 の表示 `[フットバース, グリンボー, カルゲンジー, ピッグローラー]`
- 4フレームホールド後の 11:46:26 の表示 `[グリンボー, カルゲンジー, ピッグローラー, ラピニアール]`
  → **1行だけ**移動（本来4行進むはず）

つまりカード一覧は押しっぱなしの自動リピートが効かず、v551 は観測回数を減らせず、
ホールド時間（4フレーム）だけ増やしていました。

## 修正（v552 `hanjuku-chart-v552-card-scroll-taps`）

- 行数計算 `_card_scroll_frames`（v551）はそのまま使い、送出だけを
  **同じ方向の個別タップの並び**（`[pad('down'), pad('down'), ...]`）に変更しました。
- 着地点は従来どおり次の観測で読み、選択前に必ず確認します。
- 行数が1のときは従来どおり1タップ。

## 確認

- `tests/test_hanjuku_departure_request.py`: まとめ送りが**ホールドではなくタップの並び**で
  あることを検証するアサーションを追加（既存の行数テストは維持）。
- 切り札・出撃関連 27件 passed。
- 本番反映後: `card_scroll` の**観測回数**が1出撃あたり数回に減ることを実測する
  （v551のホールドでは減らなかった）。
