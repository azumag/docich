# 出撃元はXメニューの「しろ」からSELECTで飛ぶ（v462、2026-11-06）

## 指示

オーナー指示（2026-11-06）: 出撃計画で「どの城からどの城へ出撃する」とき、出発地点の城は
Yの全体マップで飛ばず、Xメニューで「しろ」を選び、そこから城の名前を選んでSELECTボタンを押して飛ぶ。
公式マニュアル p.15 も同じ操作を説明している（「自国の城の一覧。Aボタンで各城の状態もチェックできる。
将軍と同じく、セレクトボタンでその城へ飛べるよ。」）。

## 実測した画面（隔離エミュレータ、第1章）

- メインメニュー: ステータス / しょうぐん / しろ / きりふだ / システム / けんのけいこ / セーブ。
  「しろ」にカーソルを合わせると「わがくにの すべてのしろを みることができますぞ!」。
- しろ一覧: 左に島の縮小図、右に自国城の一覧。城名は将軍一覧と同じ x=168、16px 行（y=39, 55, ...）、
  左にオレンジの手、城名の右にレベル。下に
  「Aボタンでステータスひょうじ Bボタンでコマンドにもどりますじゃ!」。
- 一覧でAを押すと城の状態（城名・しゅうにゅう・レベル・しょうぐん数・在城将軍）が開いた。

## 変更

- `flows/map.py`: 出撃元が遠いときの `_want_y_jump(..., 'map')` を廃止し、`castle_jump_step` を追加。
  X→しろ→城名→SELECT の順に操作し、SELECT後にフィールドへ戻ったら屋根検出に依存せずAで城メニューを開く（v466修正）。
  城名は `ー` を除いて照合する（チャートの「アルマムーン」と画面の「アルマームン」）。
  一覧は x=168 の16px行と、A/Bの案内文で識別する。将軍一覧は城名が無いので一致しない。
- `orchestrator.py`: `castle_jump` 実行中は他の画面処理より先にこの手順へ渡す。
- 失敗時は `castle_jump_failed` を記録し、40観測のクールダウン後に再試行する。出撃元をYで飛ぶ経路は残さない。
- 出撃先（マーカー）のYジャンプは従来どおり。

## 未確認・残件

- 隔離プローブでは、一覧でSELECTを送ったつもりが城の状態画面が開いた。Aの押下が残った可能性があり、
  SELECTで飛ぶことは実機で未確認。公式マニュアルとオーナー指示を根拠に実装した。
- 実機で `castle_jump_open` → `castle_jump_confirm` が出て、出撃元の城メニューが開くかを確認する。
  SELECTが状態画面を開く場合は `castle_jump_status` が記録され、1回だけBで戻して再試行し、
  それでも駄目なら `castle_jump_failed` で通常移動へ戻る。
- 城が8つ以上ある章の一覧スクロールは、将軍一覧と同じ16px行を前提にしている。実機の折返しは未確認。
