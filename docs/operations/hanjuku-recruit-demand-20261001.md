# 募集需要と実人数・通常収支（v121）

base main 2a4e8cecf1db0302510cce47b42e8603acf04f08。v114再評価・v115主人公退却・v118同名救済札・v120卵修理の割込み予算/上限根拠/既存ring保存を保持。保留PR1465のcontroller機能には依存しない。

## 承認された条件

基本需要は「所有城ごとの守備・交代2人＋攻略3人」。6城なら15人であり、旧v113の実一覧1画面6人で停止する固定capは削除する。章のRECRUITMENT_BY_CHAPTERと採用済みchart.recruitmentのper_castle/attackを検証して上書きできる。ゲーム上限32人を越えない。城の所有・役割が不明なら需要も不明とする。

人数需要は強制雇用ではない。新鮮な完全一覧の総賃金に候補最大15Gを加え、通常の実城収入合計で払えることを要求する。50Gの支払い後も既存の賃金予備30G・卵回復・主人公卵修理・未購入の計画札の予約を残す。恒常的な大凶作1/4係数は採用しない。

## 取得と不明の扱い

既存のメインメニュー「しょうぐん」全一覧を使う。同じ章/月の一回のscanでページを横断し、状態表示で本人を照合、下方向へ進め、異なる将軍を経て先頭へ戻ったことと全ページ名/照合済み名の一致を完全性の条件とする。主人公1名だけの場合は、メインメニューから開いた最初の一覧がどうし1名で、残り7行の名前領域全pixelが既知の空欄背景であり、本人status照合後のDownと有限再試行を経ても同じ完全空欄が3観測安定することを要求する。不変cursorだけ、部分OCR、未描画/未知pixel、任意の最後の1名ページは完了条件にならない。この単独用空欄署名は合成pixel回帰済みだが、実ラン単独global一覧画像での自然発火は未検証。城駐留者だけの一覧、繰返した同じページ、上限終了も完全総数にならない。部分scanの下限が需要以上なら募集不要を証明できるが、下限が需要未満でも不足とは断定しない。

賃金は同版の不変表（hanjuku-sfc-speedrun 5e982942、char.csv SFC IDs0..127）を実在/本人照合済み名にだけ突き合わせる。候補最大賃金15Gは同表と回帰で検証。旧house_eggs、旧名簿、支払い件数を現在の人数へ加算しない。未知名/賃金は不明。賃金のためだけの追加個別画面は開かず、既存の卵確認パネルと同時照合する。

欠測した城の収入だけを、既に実測されたY移動→自軍屋根整列→城ステータスで確認する。新鮮な実読値は城名・現所有・章/月/400観測以内で照合する。第1/2話はgcgxの城別SFC固定表と実読値が一致し、Y旗または2回の屋根観測/収入確認前の自軍屋根で現在所有を400観測以内に確認できた場合、基礎収入属性として元の取得tick/月を変更せず再利用する。表から未観測値を補充しない。不一致・未支持章・取得tick未来・古い/敵/別章の所有証拠は静的再利用しない。通常収入はcastle.htmlの「城レベルで増えない」という実測と01/02の同章城別表、同ラン第2話本城30G実観測に対応するもの。百姓係数は月の総収入側なので通常属性へ反映しない。守備を出撃させず、有料操作はしない。収入確認は各段階24観測/全セッション1200観測以内。読み取れない場合は通常進行へ戻す。

field scanは通常1回＋再確認1回まで/月、再試行間隔200観測。月切替ではrosterを無条件に再日付付けせず、月初の「メインメニュー」から当月全一覧を取り直して月初メニューへBで戻る別の有限surveyを用意する。当月surveyは移動/開く段階を含め各24観測、通常1回＋再確認1回まで。既存の卵回復と支払い中会話を優先し、surveyから修理派遣や有料処理を開始しない。次月は再開できる。失敗はrecruit_holdに具体的理由を記録し、同じ保留で通知ログを反復しない。月/章変更・加入・募集終了/支払い・HP敗北で名簿を失効する。HP敗北を死亡と断定しない。移動だけでは不変賃金やグローバル在籍数を増減せず、配置の出撃guardは既存の実在/守備確認を維持する。

前章の完全実一覧に雇用された将軍が新章の実一覧へ未到着の場合、recruit_payroll_pendingを保持し、見えている人数の賃金下限を総額として使わない。全員を同一完全scanで再確認するまで給与総額は不明とする。未到着者の給与タイミング/一覧表現はまだ実画面未校正であり、給与除外・死亡・解雇を推測して解除しない。

既にopened/done/unverifiedとなった募集会話は追跡を保って完了させる。人数が十分に見えたからといって取消・返金は推測しない。
