# 本城に将軍がいないときは出撃元を諦めない（v423、2026-11-05）

## 症状（実測）

ボス指示 `A:bf8c3dee:M256898` で `source_miss` が **5のまま1時間以上**、
`_give_up_source` が毎観測走り、注文は**歩き出す前**に毎回フォールバックへ入っていた。

- v419 の probe 224件はすべて `override: null` / `source_miss: 5` /
  `source: オケアナ` / `home: アルマムーン` / **`home_garrison: []`**。
- v422 でミスの戻しを pop から代入に変えても、この経路の書き込みは残らず `source_miss` は 5 のまま。
- つまりフォールバック先（本城）に将軍がおらず、**切り替えても出撃できない**のに、
  毎回そこで足止めされていた。

## 変更

- `flows/map.py` に `_home_can_send(mem)` を追加（本城の実測名簿に将軍がいるか）。
- 出撃元を諦めるのは**本城に将軍がいるときだけ**にした。いなければ諦めずに、
  チャートの出撃元（オケアナ）へ向かって歩く。
- 診断用に入れていた `source_giveup_probe` と `_source_giveup_stuck` は役目を終えたので撤去。

## 検証

- `tests/test_hanjuku_giveup_fallback.py` を新仕様に更新（本城が空なら送れない／将軍がいれば送れる）。
- 関連（`off_chart` / `miss_reset` / `chart_bot` / 層）427 passed。
