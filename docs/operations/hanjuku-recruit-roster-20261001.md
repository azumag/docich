# 直近の実一覧で十分な将軍を確認したら募集しない

ユーザーは将軍が十分いるのに募集が毎月繰り返されると指摘した。既存ルールは駐留・移動記録の下限が6未満なら優先募集し、それ以外でも兵士99と余剰資金があれば募集していた。実際の全体一覧の観測は人数判断に接続されていなかった。

v113は既存parserが読めた将軍一覧の1画面で重複なし6人以上を確認したら、当該章の400観測以内に限り追加募集を抑止する。これは総人数ではなく実表示からの下限。別ページの少ない人数を総人数としない。古いhouse_eggsの累積名簿は使用しない。

未開始の募集はnot_neededにし、古い優先募集フラグ・予約費を解除。すでにopened/done/unverifiedの募集は支払い取消や人数増加を推測しない。古い/未来tick・別章・6人未満の部分観測だけでは十分と扱わない。人数目標は既存の6から変更しない。画像認識を追加実行せず既存parse結果を利用する。

専用8件を含むfocused355件、半熟集約1491 passed /1 skipped /1 deselected。除外は未初期化knowledge submoduleの既存依存1件。compile/diff check。独立レビューなし。現ランでの次の募集抑止は正規配備後に確認する。
