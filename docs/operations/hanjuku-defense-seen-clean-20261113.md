# 半熟英雄: 自軍でない城の防衛シグナルを捨てる（v790、2026-11-13）

## 症状

`defense_seen` は城名ごとに900 tick保持されます。`オオキク` を失って敵の
ものになった後も `defense_seen['オオキク']=141424` が残っていました。
再奪還した直後にこの古い窓が残っていると、奪ったばかりの城に
「直近に攻められた前線」のルール（v765の2人残す / v771の最強を在城）が
誤って適用されます。

```
defense_seen = {"オオキク": 141424, ...}   # オオキクは敵
```

## 修正（v790 `hanjuku-chart-v790-defense-seen-clean`）

`corridor.orders()` の先頭で、自軍でない城の `defense_seen` も削除します
（v783/v785/v786 の前線タイマー掃除と同じ場所）。

- 自軍の城の `defense_seen` は保持。
- 再奪還した城は新しい防衛シグナルから始まる。

## 検証

- 新規 `test_defense_seen_for_a_castle_no_longer_ours_is_dropped`:
  敵城のエントリが消え、自城のエントリは残る。
- corridor / 前線 / capture guard / 派遣 関連 **185件 passed**。
- 修正前の `corridor.py` では新テストが失敗することを確認。

## 本番反映後に実測すること

- 敵城の `defense_seen` が残らないこと。
- 再奪還した城で v765/v771 の防衛ルールが古い窓で誤発動しないこと。
- 第9話の進行と12話ボス撃破は引き続き実測で確認する。
