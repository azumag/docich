# 半熟英雄: ボスへ効く切り札を積極的に使う v384（2026-11-04）

## オーナー指示

「ボスモンスターにも切り札は効くものがあるので、積極利用すること。クースカンなどは効かないが、
バルムンクなどは有効。弱い将軍ならバグストーム自爆でもいいかも。有効な切り札はネットで調べて、
積極的につかうようにして」（2026-11-04）。

## 調査（gcgx.games/hanjuku/kirihuda.html、2026-11-04 取得。リポジトリの `CARDS` 表と一致）

ボスへのダメージ列と効果（入手）:

| 札 | ボス | 備考 |
|---|---|---|
| バルムンク | **250** | エグモン即死。クリスマス/洞窟の宝箱のみ |
| ハリケーン / ビッグウェイブ / ファバード | 100 | ファバードは自軍HP半減。ハリケーンは洞窟商人38G |
| グルミー | 100 | 攻撃半減。パロム＆ポロム限定 |
| キャトルミュー | 90 | 火星人限定（既存のレア札経路） |
| マグネガキン | 80 | 攻撃半減 |
| ドデカヘー | 70 | 防御半減 |
| リューキーシ | 60 | |
| ゼンマイン / バグストーム | 50 | バグストームは両軍の将軍・兵士HP半減 |
| クースカン | 20 | HP半減はボス・エグモンに効かない |
| ノリウツール | 8 | |

gcgx の攻略メモ: 多くのボスは退却するたびにHPが回復する（将軍が倒された場合は回復しない）ため、
不要な将軍を削り役として使い切るのが有効。

## 変更

1. **バルムンクを全章のボス注文で先頭携行（`flows/deploy.py`）**
   これまで第2話 2-B1 だけだった。全章のボス注文（基礎・調整・波状の追加隊）で、
   未選択の札一覧にバルムンク（実在庫）を確認したら、`バルムンク x min(在庫,2)` を先頭に、
   予定札を携行枠3・ID合計47以下の範囲で後ろに続ける（`rare_card_kit`）。
   2-B1 は実プレイ検証済みの専用キット（イッテツーン＋バルムンク2）を変えない。
   月の探索で見えたバルムンクの在庫は `balmung_held` に月単位で残し、別の出撃の4行窓に
   見えなくても次のボス出撃が使う（一覧が不在を証明するか月が変われば消える）。
2. **バルムンクの開幕戦術（`strategy/orders.py`）**
   携行した枚数ぶん、ボス突入の実測後にだけ開幕で使う（`boss_only`）。調整・波状の注文でも
   既定戦術と重複させない。
3. **モンスター型ボスの追加携行（第5話以降、四季王を除く）**
   強い切り札の追加携行は、クースカン等の半減札ではなくボスダメージ列の大きい順
   （`reference.BOSS_DAMAGE_CARDS`）から選ぶ。最大HP50以下の弱い将軍の出撃だけ
   バグストームも候補に入れる（`reference.BOSS_SACRIFICE_CARDS`、使い捨ての自爆）。
   クイーン/にせヒーロー/プリンスなど将軍型ボスと通常の出撃は従来どおり。

## 変えないこと

- 基礎チャートのボス戦術（マグネガキン開幕・ファバードなど）と厳密なボス札キット。
- 強い将軍/弱い将軍の判定、弱い将軍で強い札を温存する規則。
