# 半熟英雄: ボスへ効く切り札を積極的に使う v384（2026-11-04）

## オーナー指示

「ボスモンスターにも切り札は効くものがあるので、積極利用すること。クースカンなどは効かないが、
バルムンクなどは有効。弱い将軍ならバグストーム自爆でもいいかも。有効な切り札はネットで調べて、
積極的につかうようにして」（2026-11-04）。

## 調査（gcgx.games/hanjuku/kirihuda.html、2026-11-04 取得。リポジトリの `CARDS` 表と一致）

ボスへのダメージ列と効果（入手）:

| 札 | ボス | 備考 |
|---|---|---|
| バルムンク | **250** | エグモン即死。クリスマス/洞窟の宝箱のみ |
| ハリケーン / ビッグウェイブ / ファバード | 100 | ファバードは自軍HP半減。ハリケーンは洞窟商人38G |
| グルミー | 100 | 攻撃半減。パロム＆ポロム限定 |
| キャトルミュー | 90 | 火星人限定（既存のレア札経路） |
| マグネガキン | 80 | 攻撃半減 |
| ドデカヘー | 70 | 防御半減 |
| リューキーシ | 60 | |
| ゼンマイン / バグストーム | 50 | バグストームは両軍の将軍・兵士HP半減 |
| クースカン | 20 | HP半減はボス・エグモンに効かない |
| ノリウツール | 8 | |

gcgx の攻略メモ: 多くのボスは退却するたびにHPが回復する（将軍が倒された場合は回復しない）ため、
不要な将軍を削り役として使い切るのが有効。

## 変更

1. **バルムンクを全章のボス注文で先頭携行（`flows/deploy.py`）**
   これまで第2話 2-B1 だけだった。全章のボス注文（基礎・調整・波状の追加隊）で、
   未選択の札一覧にバルムンク（実在庫）を確認したら、`バルムンク x min(在庫,2)` を先頭に、
   予定札を携行枠3・ID合計47以下の範囲で後ろに続ける（`rare_card_kit`）。
   2-B1 は実プレイ検証済みの専用キット（イッテツーン＋バルムンク2）を変えない。
   月の探索で見えたバルムンクの在庫は `balmung_held` に月単位で残し、別の出撃の4行窓に
   見えなくても次のボス出撃が使う（一覧が不在を証明するか月が変われば消える）。
2. **バルムンクの開幕戦術（`strategy/orders.py`）**
   携行した枚数ぶん、ボス突入の実測後にだけ開幕で使う（`boss_only`）。調整・波状の注文でも
   既定戦術と重複させない。
3. **モンスター型ボスの追加携行（第5話以降、四季王を除く）**
   強い切り札の追加携行は、クースカン等の半減札ではなくボスダメージ列の大きい順
   （`reference.BOSS_DAMAGE_CARDS`）から選ぶ。卵を持たず（エッグ種別「－」）、最大HP50以下かつ戦闘5以下の弱い将軍
   （`reference.sacrifice_general`、gcgx 将軍表に載る名前だけ）の出撃に限って
   バグストームも候補に入れる（`reference.BOSS_SACRIFICE_CARDS`、使い捨ての自爆）。
   2026-11-04 オーナー追加指示で「卵なし・戦闘力が弱い」を条件に追加。
   クイーン/にせヒーロー/プリンスなど将軍型ボスと通常の出撃は従来どおり。

## 変えないこと

- 基礎チャートのボス戦術（マグネガキン開幕・ファバードなど）と厳密なボス札キット。
- 強い将軍/弱い将軍の判定、弱い将軍で強い札を温存する規則。

## 確認

- `tests/test_hanjuku_boss_balmung_generic.py`（新規）と、関連する既存テストが通ること。
- 実プレイでの成立は未確認。デプロイ後、バルムンク在庫がある月のボス出撃で
  `rare_card_kit`（card=バルムンク）→ 実携行確認 → `battle_card`（バルムンク）の順に
  記録されることを確認する。テストの成功を実機の成立とは扱わない。

## 追補（2026-11-08）通常の出撃には携行しない

owner 2026-11-08、g1153 13:21 の実プレイ報告による。ココット（HP24/戦闘8）が
ドンダムへバルムンクを携行して出撃し、守備将軍ゼウス（HP85/戦闘13）との戦闘で
一度も使えず敗北、バルムンクを失った。

- 出撃側は「卵落5が最強」として、記録上の守備将軍シャルドネの卵落としに
  バルムンクを選んでいた（`_dropper_card_inventory`）。第3話の基礎チャートには
  ボス注文がなく `boss_kit()` が None のため、ボス用の予約が働かず「余剰」と
  みなされていた。
- 戦闘側は上のボス専用ルールで、ボス突入の実測前はバルムンクをすべての戦術から
  除外する。通常戦では卵落としにも使えない。
- さらに、敗北後の再攻撃計画が在庫0のイッテツーン2枚を固定で予定し、
  `planned_cards` に残ったことが退却判定（`_resources_exhausted`）を塞いだ。
  白兵スコア 112 対 1105（約1:10）でも退却せず、HP0まで押し込まれた。

変更:

- `reference.BOSS_ONLY_CARDS`（バルムンク）を追加し、通常の出撃の追加札
  （卵落とし・強い札）から外す（`boss_card_reserved`）。
- 調整チャートの既定戦術（`d:`）でもボス専用札は `boss_only` にする。
- `planned_cards` は実測した出撃の携行札と使用可能な札だけにする
  （`_planned_battle_cards`）。
- 再攻撃の開幕札は実在庫の枚数だけ計画する（在庫0ならチャート装備のまま）。

変えないこと: ボス注文のバルムンク携行（`rare_card_kit`）とボス突入後の使用。
バルムンクの将軍ダメージは16なので、通常戦で使っても勝敗は変わらない
（本件のゼウス85には焼け石に水）。
