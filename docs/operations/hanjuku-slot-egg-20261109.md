# スロットエッグの回転をエラベルの三択と取り違える滞留

2026-11-09 JST の配信画面で、第8話の卵表示に
メトロノーム／ハズレ／レッドドラゴンを確認した。
オーナーの確認により、この表示はエラベルエッグの静止した三択ではなく、
高速回転するスロットエッグの一瞬である。

従来は既知召喚獣名3行しか認識せず、ハズレが混ざると入力を保留した。
召喚獣名だけの瞬間も先頭行へ上下移動するため、回転を止めるAに到達しない。

v591では固定位置の完全な3行（既知召喚獣または実表示のハズレ）を読み、
現在の戦闘の味方将軍に記録された `egg_types == スロットエッグ`、
またはスロット固有のハズレ表示を根拠に回転として扱う。
同じ卵表示の間は判別を保持する。召喚獣名3行という外見だけや、別将軍の
卵種、名前の変化だけではスロットと断定しない。

スロットでは騎士の位置へ上下移動せずAで停止を要求する。
表示時点の名前を停止結果や狙った召喚獣とは記録しない。
3観測待って最大1回だけ再試行する。回転による候補名の変化、騎士の点滅、
途中の読取不能フレームでは入力予算を補充しない。
戦闘や召喚後メニューなどへの実遷移で卵表示の追跡を破棄する。
未知の文字・欠けた行・別配置には停止入力を出さない。
大ハズレのゲーム内表記と字形は今回未校正であり、認識対象を推測で増やさない。

回帰は実表示を再現した合成フレーム、記録した卵種、回転する名前と騎士、
旧版の保留状態、途中の読取不能、再試行上限、召喚後の解除を検証する。
静止画の再生は実リール停止・召喚成功の証明ではなく、配備後の画面遷移は別確認。
