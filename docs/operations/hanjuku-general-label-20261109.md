# 半熟英雄: 出撃計画の「しょうぐんで攻撃」を読みやすくする（v568、2026-11-09 オーナー指摘）

## 指摘

「出撃計画に『しょうぐん』出てくるのはおかしいよね　しょうぐんは出撃実質しない設定なのでは？」

## 事実確認

- `しょうぐん` は **将軍名ではなく内部の番兵値**（`MOVE_ANY_GENERAL`）で、
  「その城の実一覧を開いて余剰の将軍を選ぶ」という意味です（`source_probe: True` と対）。
- 主人公は **どうし**（`chart.HERO`）で、出撃しません:
  `_spares` が除外、`hero_priority_selected` が代役に差し替え、
  `chart_adjust.startable` が主人公の注文を拒否します。
- 実測（16:24 の計画）: 注文は1件 `しょうぐん アルマムーン→フィロメラ`（`source_probe: True`）で、
  主人公は計画に含まれていませんでした。

問題は**表示**で、注文のメモが「暫定: しょうぐんで◯◯を攻撃」と出ていたため、
将軍「しょうぐん」が攻撃しているように読めていました。

## 修正（v568 `hanjuku-chart-v568-general-label`）

- `replan._general_label(general)`: 番兵値のときは **「一覧の余剰」** と表示する。
- 暫定注文のメモ（攻撃・奪還・ボス波・防衛移動・増援移動）をこの表記へ変更。
- 内部の番兵値（`しょうぐん`）はそのままです（スキーマ検証・LLMとの契約を壊さない）。

## 確認

- `tests/test_hanjuku_off_chart.py` に1件追加: 番兵値は「一覧の余剰」、将軍名はそのまま。
- 計画・ボス波・偵察・未読出撃元 133件 passed。
- 本番反映後: 出撃計画のメモが「暫定: 一覧の余剰で◯◯を攻撃」になることを実測する。
  （配信側の一覧に残る「general」欄は Soren 側の表示で、番兵値をそのまま出しています。必要なら
  soviet_now 側で同じ表記に置き換える別対応を行います。）
