# 半熟英雄: 切り札一覧から抜けられない時にAで進める（v624、2026-11-10 オーナー指摘）

## 指摘（オーナー）

「まだながはまから出撃できてないよ」

## 実測（08:39〜08:40）

ながはまに飛び、将軍一覧でアルテミスを見つけた後:

```
保留 ×5（切り札一覧…構造不一致）→ card_list_unreadable_depart（Bで閉じる）
→ それでも画面は切り札一覧のまま（候補にアルテミス/しょうぐん）
→ 出撃確認の保留 ×6 → 盲承認A×2 → 出撃せず order_start からやり直し
```

**B1回では切り札一覧が閉じず**、以後「出撃確認」の処理が切り札一覧の上で走って
空振りしていました（同じ出撃の無限ループ）。

## 修正（v624 `hanjuku-chart-v624-card-list-escape`）

`card_skip_departure[step]` を**回数**に変え、

1. 1回目: 従来どおり **B**（一覧を閉じる）
2. 2〜4回目: まだ一覧に居るなら **A**（ハイライト中の札を取る）で先へ進める
3. 5回目: それでも抜けられなければ従来どおり取り消し（B×2）

切り札の最終的な確定は出撃確認側（読めた携行札が真実／盲承認）で行います。
