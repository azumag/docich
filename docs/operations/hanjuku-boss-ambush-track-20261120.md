## 追記: 軌道を分担し、待ち伏せを維持する

- 待ち伏せセルは将軍ごとに軌道を分担（将軍名のソート順で軌道セルを割り当て）。
  全員が同じ点へ向かうのではなく、軌道全体をカバーする。
- 待ち伏せ配置した将軍は `ambush_until`（`AMBUSH_WAIT_TICKS=1200`）まで再照準しない。
  4分ごとの再照準では、ボスが周回してくる前に将軍が動いてしまうため。
- 追加テスト2件（軌道の分担／待ち伏せ中の候補除外）。

## 追記（v1275）: 待ち伏せの待機を1時間へ（初のボス交戦を実測）

2026-11-20 20:46、待ち伏せ将軍へのボス接触で**初のボス交戦**を記録
（`hanjuku_month_audit` の `boss.battle_count = 1`、`battle_at` 20:46:09、
`boss_ambush_contact` も記録）。配置から約46分後の接触で、20分の待機では
1周に足りない。`AMBUSH_WAIT_TICKS` を 1200 → **3600**（1時間）へ広げ、
ボスが軌道を1周して戻るまで将軍を待たせる。

## 追記（v1281）: 待機を15分へ戻し、配置の実測サンプルを増やす

オーナー指摘（2026-11-21）「全然軌道上に配置できてない」を受け、配置検証
（v1280 の `unit_world`）のサンプルを増やすため `AMBUSH_WAIT_TICKS` を
3600 → **900（15分）** に短縮。初回接触（20:46）の将軍は待機中に2回再照準
されても接触しており、再照準先も軌道セルなので待ち伏せは失われない。
これで同一将軍の `unit_world` を15分間隔で比較でき、軌道セルへ移動できて
いるかを判定できる。

## 追記（v1282）: 将軍待ちをやめる（オーナー指示 2026-11-21）

> ボスは卵を使われるとハデスが召喚され6666HPになるが、卵を使われる前に
> 切り札バルムンクｘ２を使うのが正解。ただしバルムンクがなければそのまま
> 通常戦闘するしかない。波状攻撃でも削れるので、将軍待ちやバルムンク待ちは
> 絶対にしない。

- `AMBUSH_WAIT_TICKS` を 900 → **0**。待ち伏せ後に将軍を遊ばせず、
  通常の追撃クールダウン（`PURSUIT_COOLDOWN=240`）で次の波を出す。
- 待機を前提にしたテストを「配置後も次の追撃を妨げない」に更新。
- バルムンクx2の開幕使用は、チャート注文のボス戦では実装済み
  （`orders.tactics` の `rare:...:バルムンク`、`open=True`）。
  待ち伏せ由来のボス戦（注文なし）でも同じ開幕札を使えるよう、
  次に対戦相手と携行札の対応を配線する。
