# 半熟英雄: 待ち伏せを軌道全体へ分散する（v1322、2026-11-21）

## 症状（本番 g1288 18:5x の実測）

待ち伏せ4名の `ambush_cell` が **すべて x=674 列**（[674,212] [674,317] [674,333] と
その周辺）に集中し、ボスは `[874,709]` など **x 658〜874** を移動していた。
軌道の西端に固まっており、ボスが来る確率が低かった。

## 原因

`boss_pursuit._ambush` は将軍のインデックスで `distinct[index % len(distinct)]`
を選んでいた。`distinct` は座標の昇順ソートなので、**先頭4セル＝西端**が
4将軍に割り当てられていた（「各将軍が違うセル」の意図に反して密集）。

## 変更

- インデックスを軌道全体へ**ストライド**配置:
  `pos = index * len(distinct) // len(names)`。
  4将軍・16セルなら 0/4/8/12 番目（西→東→南へ分散）。
- `BOT_VERSION` v1322、hot-load許可リストへ追加。

## 検証

- `tests/test_hanjuku_ambush_spread.py`（2件）: 4将軍が分散し、東側(x>=800)も含む。
- 待ち伏せ・追撃系 25 passed。

## 期待

- 待ち伏せが軌道全体（南東バンド含む）に分散し、ボスとの接触確率が上がる。
