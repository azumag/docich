# 半熟英雄: ボスへの波は「卵が生きている将軍」を距離より優先する（v558、2026-11-09）

## 症状

g1163 第6話 2026-11-09 13:36:33 JST。第6話ボス（ハードロボ HP152）へ ヘーゼル が突入し、
`egg_battle_menu` で「たまごをつかうが使えない」→ こうげき で応戦 → 約1分半で敗走。
ボスのHPは **152 のまま**（1点も削れず）。

同じ章には卵の残っている将軍が複数いました。

## 原因

`_boss_wave_pick` の並びが
`(使用済みか, 主人公の城か, **距離**, 卵ランク, 城名, 将軍)` で、**卵ランクより距離が優先**。
近い城の「卵が使えない将軍」が、遠い城の「卵が生きている将軍」より先に選ばれていました。

ボス戦のダメージは卵（召喚獣）が担う（owner 2026-11-05）ため、卵の無い将軍は
ボスへ行っても削れずに失われるだけです。

## 修正（v558 `hanjuku-chart-v558-boss-wave-egg-first`）

並びを `(使用済みか, 主人公の城か, **卵ランク**, 距離, 城名, 将軍)` に変更。
卵ランクは `_boss_egg_rank`（0=良好 / 1=不明 / 2=破損・使用済み）。

- 城の選択（未使用の城を優先・主人公の城を後回し）と距離の同ランク内順序は従来どおり。
- 卵の状態が未読の将軍は「1」なので、壊れた将軍（2）より先に選ばれる。

## 確認

- `tests/test_hanjuku_boss_wave_solo.py` に1件追加: 近い城の卵なし将軍より、遠い城の
  卵あり将軍が選ばれる。
- ボス波・ボス偵察・ファントムstep・出撃・チャート 436件 passed。
- 本番反映後: ボス突入将軍が卵持ちになり、`boss_hp_seen` のHPが実際に減ることを実測する。
