# 半熟英雄: 15分ごとにセーブステートを取る（v623、2026-11-10）

## 背景（実測）

コーナーが落ちたときの復帰先を調べたところ、セーブステートは **23:14 の1つだけ**で、
**9時間ぶんの進行（章7→8、8城占領）が失われる**状態でした。

## 変更

- `[lifecycle] periodic_savestate_s`（任意・秒）を追加。指定した間隔で
  RetroArch の network command `SAVE_STATE` を送ります。
- 既定は未設定（従来どおり）。エージェントループの動作・間隔には影響しません。
- 半熟の設定に `periodic_savestate_s = 900`（15分）を追加。

## 即時対応（実測済み）

反映を待たず、`SAVE_STATE` を1回送って**現在の状態を保存**しました
（`states/hanjuku-hero.state` の mtime が 23:14 → **08:27** に更新されたことを確認）。

## 確認

- `tests/test_config.py`（opt-in と不正値の拒否）、
  `tests/test_agent_loop_savestate.py`（間隔の境界とキー未設定時の無効）を追加。
- config・ループ・アダプタ 44+2件 passed。
- 次回エージェント起動時から15分ごとに保存されます（設定は起動時に読まれます）。
