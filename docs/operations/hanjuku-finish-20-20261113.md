# 半熟英雄: 守備将軍を20HPまで「止め」とみなす（v767、2026-11-13）

## 症状（実測 g1163 2026-11-13 14:5x）

第9話 `ナッテ` への攻撃で、守備将軍を **enemy HP 16** まで削りましたが
`lost` になりました。

```
14:5x ナッテ  lost  enemy_hp=16
```

`_defender_nearly_dead()` の `FINISHING_HP=10` では 16 は「止め」と
みなされず、2人待ち・前線ガードの対象のままでした。次の攻撃が保留される間に
守備将軍が回復し、再攻撃の機会を逃していました。

## 修正（v767 `hanjuku-chart-v767-finish-20`）

`FINISHING_HP` を **20** に引き上げます。

- 守備将軍が 20 HP 以下（パネル読みまたは直近の戦闘結果）なら `_finish` と
  みなし、前線の人数待ち・1人ガードを飛ばして止めを刺しに行く。
- 元気な将軍を先頭にする v762 と組み合わせ、20 HP は一撃で落とせる範囲。
- 21 HP 以上は従来どおり。

## 検証

- 新規 `test_a_sixteen_hp_defender_is_a_finish`: enemy_hp=16 の直近結果で、
  前線1人でも攻撃に出る（`front_wounded` を記録しない）。
- 既存の3HP・パネル読みの止めテストはそのまま passed。
- corridor / 派遣 / 城ルート / 前線 / capture guard / probe 関連
  **203件 passed**。
- 修正前の `corridor.py` では新テストが失敗することを確認。

## 本番反映後に実測すること

- 守備将軍を 11〜20 HP まで削った直後に、次の攻撃が待たずに出ること。
- `ナッテ` のような 16 HP の守備将軍を落とせること。
- 20 HP 以下で無理な単独攻撃をして逆に落とされる、という悪化がないこと。

## 残件

- 「止め」の閾値はゲームの与ダメージ分布に依存する。20 で足りない/過剰なら
  実測で調整する。
- 第9話の進行と12話ボス撃破は引き続き実測で確認する。
