# 半熟英雄の将軍戦闘力を含む判断（2026-10-12）

オーナー指摘「有利不利の判定に各将軍の戦闘力が入ってなさそう」と、
「両将軍の戦闘力・HPが優勢で兵士も減っていない開幕で卵を使っている」に対応する。
以前から強敵分類とクースカン後の追撃には戦闘値が入っていたが、HP中心の
劣勢・卵温存・優勢時の退却抑止では、両軍の戦闘値が比較に入っていなかった。

v175 の共有比較は、実画面から読んだ現在HPと両側の現在兵数、既存128名表で
名前を照合した各将軍の戦闘値を使う。

```
HPプール = 現在HP + 10 × 現在の兵数
比較スコア = HPプール × その将軍の戦闘値
```

これは操作判断の近似スコアで、ゲームの正確なダメージ式や勝率ではない。
[既存解析の戦闘説明](https://gcgx.games/hanjuku/battle.html)の兵士HP10と、
[将軍パラメータ](https://gcgx.games/hanjuku/shogun.html)の戦闘値が攻撃力に影響する
という情報を使う。城・季節・地形の速度補正、兵士の個々の残HP、召喚獣の能力を
この式から推測しない。将軍の攻撃値を召喚獣の技評価へ適用しない。

兵数は current marker が真で、HP/文脈の無効化がなく、両側とも整数0..6の
場合だけ使う。一方でも未読・無効・古ければ両側とも兵数を加算しない。
戦闘値は各本人の固定表の整数1..15だけを使い、不明なら卵温存や退却抑止の
根拠にしない。g713ゼウス原画面の7個のシルエットは7人の兵士と解釈せず、
共有スコアは両側HPだけへ戻す。既存の当該原画面の退却抑止対照は保持する。

HP28/39・戦闘1のカシュー対HP18・戦闘3のチコリ（兵数0/0）の対照では、
旧HP比較の「28 > 18」が近似スコア「28 < 54」へ変わる。実勝敗の証拠ではなく、
戦闘力を落とさないための合成入力である。実現在兵1/0ならHPプール38/18と
なり、卵を必要とする70%閾値の結果も変わる。

`_behind`、チャート戦術のない通常戦の追加救済、卵温存、優勢時退却抑止で
共有値を使う。HP大破・危険HP・主人公・ボス・敵召喚の既存保護を保持する。
卵温存で白兵へ戻るには健全な本人HPとHPプールの最低余裕も必要であり、
戦闘力だけで極端な人数不足を安全扱いしない。残数0は使わず、読める卵ラベルを「温存できる救済資源」とも扱わない。
保存済み温存のfield再確認も本人0を拒否し、実menuでの枯渇と退却判断を保持する。

通常将軍の健全な白兵優位を実測した場合は、切り札欄がなくても卵を温存する。
旧ガードは切り札欄を必須とし、札探索後の救済経路から不要な卵へ進んでいた。
温存を「救済手段が尽きた」と扱わず、同じ優位が続く間のメニュー再巡回を抑える。
新たな危険HP・敵召喚・未読で温存許可を失い、実兵数変化で使える札が変わった時の
有限再確認を維持する。実切り札の先行確認と既存の試行上限は保持する。
開幕の兵数6/6・ヴィーナス82/戦闘12対カシュー39/戦闘1の合成メニューで、
切り札欄なしでもBで白兵へ戻り、卵選択/消費/退却を作らないことを検査する。
これは指摘された特定の試合の原画面再現とは別の回帰対照である。

戦闘メニュー/卵召喚の学習キーはctx4と本人の両戦闘値を含める。ctx3以前の
実績は消さずに保存するが、新しい比較へそのまま適用しない。明確な戦闘力不利
または戦闘値不明では、学習したattackも卵対処を上書きしない。実残数0では
この例外からも召喚しない。通常menuの学習pass/保存済みpassでも未知戦闘値が温存を許可しない。
実卵0の場合はこの見直しでも召喚しない。召喚獣の技メニューの既存キーは維持する。

判断ログに `melee_balance`（両戦闘値、HPプール、近似スコア、兵数の現在性、
方法・対象）を追加する。値や選択から実使用・勝利・死亡・到着を作らない。
実機受入では新175のplan、同decision_idのinput、原PNGのRGB一致を確認し、
自然戦闘のこれらの値と実結果を別々に照合する。現在のゲーム・共有配信・音声を
終了/再起動せず、正規PR/最新HEAD CI/main/canonical VM gatewayで反映する。

## Runtime checklist

- registry/manifest: ゲーム/worker/queueの構成変更なし。既存canonical manifest対象。
- worker health/queue: owner、lane、PID、ユーザー休止を維持。
- telemetry: 有限の数値・固定method・名前照合の判断証拠を追加。
- diagnostics: v175の固定version allowlistとredaction回帰を追加。
- regression: HPと戦闘力が逆転する対照、現在/未知兵数、無効/未知戦闘値、
  学習ctx3分離、危険HP/主人公/ボス/召喚/卵0、既存native優勢退却を検査。
- secret-redaction: token/prompt/環境変数を取得・出力しない。
- deploy: 同ランへの既存hotload。新PIDへの入替・共通service restartは不要。
