# 半熟英雄: ボス戦の灰色卵行は記録だけにする（v562の取り消し、v563、2026-11-09）

## 経緯

v562（PR #3800）は、ボス戦で「たまごをつかう」の行が灰色だった将軍を
`egg_uses=0`（召喚不能）として記録し、以後のボス波から外していました。

ところが **14:55:50 の実測**で、ペコリーノが灰色の卵行のままハードロボへ突入し、
**同じ戦闘でボスHPが 152 → 70**（82ダメージ）まで減りました。
灰色の行は「召喚できない」だけで、**ボスへダメージを与えられない証明ではありません**。
v562のままでは、実際に成果を出している将軍を波から外してしまいます。

## 修正（v563 `hanjuku-chart-v563-boss-egg-row-log`）

- `egg_uses[general] = 0` の書き込みを取り消しました。
- 代わりに `egg_row_unavailable` を**記録だけ**します（同一戦闘で1回）。
- `_boss_egg_rank` の判定は変更しません（卵の実測が無い将軍は従来どおり「不明」）。

## 確認

- `tests/test_hanjuku_boss_egg_row_log.py`: 灰色行はログのみ・`egg_uses` を変えない・
  通常城ではログもしない。
- 卵・ボス波・ボスHP 79件 passed。
- 本番反映後: ペコリーノ級の将軍が引き続きボス波に選ばれ、ボスHPが減ることを実測する。
