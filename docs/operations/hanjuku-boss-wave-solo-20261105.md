# 全城制圧後は最後の1人でもボス隊を出せるようにする（v407、2026-11-05）

## 症状（実測）

第6話の通常11城を制圧した後、ボス隊を8隊出した時点で各城の守備は1人になった。
`_boss_wave_pick` は「余剰2人（1人は残留）」を要求するため、以降は新しいボス隊が
編成できず、計画は暫定の移動（ライム→オケアナ、ゼウス→カバルッサ）へ後退した。
その移動も敵の防衛戦に割り込まれて完了せず、`order_start` が5分間に10回再試行された。

## 変更

- `_boss_wave_pick`: `_post_conquest_wait(mem)`（全通常城を保持）の間は、
  **本城以外**の城なら最後の1人でもボス隊に送れるようにした。
- 本城（アルマムーン）は常に守備を残す。攻撃・奪還の2人ルールは変更しない。
- 根拠: オーナー方針「遠い城は0人まで送り出してよい（2026-11-04）」と、
  ボスが唯一の敵になる全城制圧後という条件。

## 検証

- `tests/test_hanjuku_boss_wave_solo.py`（新規3件）:
  1人城からボス隊が出る／本城だけなら出さない／全城制圧前は従来どおり出さない。
- 修正前は1件失敗、修正後 3 passed。関連（`boss_wave_double` / `boss_sortie_overdue` /
  `mechanical_conquest` / `off_chart` / 層 / `chart_bot`）を含め 482 passed。
