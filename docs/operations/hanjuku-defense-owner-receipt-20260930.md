# 半熟英雄 v106 防衛敗北後の城旗確認

## 確認した不一致

終了したg508-19169549のスペンソニア防衛で、シェーブル対クミン0対3の敗北が1790760055.2253368に記録された。直前の1790760049.0689902と1790760052.0492606のworld_map_ownersは、同じ城を含む通常７城をownとして認識していた。限定したゲームログの必要項目だけをVM内で抽出した。該当時点の旗画像は固定RGB確認できていないため、目視証拠とは区別し、旗認識ログと処理順序を根拠とする。

旧battle_endは防衛将軍のHP敗北を城の陥落と同一視し、それより新しい全体マップの所有権を上書きしていた。capturedから城を除き、他の守備将軍を含むgarrison全体を破棄し、all_captured条件も未達に戻していた。将軍の敗北から死亡は確定しない。

## 修正

同じ既知の防衛戦で本人0HP・敵生存後に、現在の章の対象城の旗をown/enemyとして読めた場合だけ、その証拠をbattle内に保持する。敗北後のownは、将軍の敗北と敗北数を記録しつつ城の所有権・他の守備将軍を保持する。敗北した将軍だけ古いgarrisonから除き所在未分類とし、死亡数は推定しない。最新enemyなら従来通り城失陥を反映する。

前章、別城、未知色、攻撃戦、敗北前、HP不明・不正型の情報を使わない。終了時にも章・城・攻防・整数HPを再検証する。新しい完全な戦闘パネルが出れば旧旗の証拠を解除し、戦闘終了後や次の守備将軍へ持ち越さない。既に消えた過去garrisonを推測で復元しない。

battle_resultのoutcome=lossは維持する。新しい実旗がownならresulting_eventをdefense_retained、観測した所有色をcastle_owner_after_defeatとして記録する。v104の２連続パネルによる守備交代はdefense_continuesのまま区別する。
