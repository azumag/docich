# 半熟英雄: 城ジャンプのフィールドに野営が見えたら帰還を優先する（v813、2026-11-14）

## 症状（実測 g1163 2026-11-14 05:28）

城ジャンプの `castle_jump_confirm` のフィールドフレームで **camps=1**（自軍
野営が見えている）と記録されました。しかし城ジャンプの確定Aがそのフレームを
消費し、城メニューを開いていました。野営帰還はフィールドの地図フレームでしか
始まらず、城ジャンプのフレームは使われていませんでした（野営 [84,73] は
`recall_retry.count=8`）。

## 修正（v813 `hanjuku-chart-v813-jump-camp-priority`）

`castle_jump_step` の確定段で、自軍野営が見えているときは
`recall_flow.camp_recall_step` の行動（帰還の入口）を優先します。

- 城ジャンプの状態（`castle_jump`）は残し、帰還の後に出撃を再開できる。
- 野営が見えないときは従来どおりAで城メニューを開く。

## 検証

- 新規 `test_a_visible_camp_takes_the_castle_jump_field_frame`:
  野営が見える城ジャンプのフレームで帰還の行動が返り、`castle_jump` が残る。
- 城ジャンプ・野営・帰還・月場面関連の既存テストを実行。
- 修正前の `map.py` では新テストが失敗することを確認。

## 本番反映後に実測すること

- 城ジャンプのフレームから `camp_found` / `camp_enter` が出ること。
- 野営帰還が成立し、城ジャンプの出撃がその後再開されること。
- 12話ボス撃破には未到達。目標は active のまま継続します。
