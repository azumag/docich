# 半熟英雄: ボスセルに味方将軍がいる攻撃を確定しない（v1287、2026-11-21）

## 症状（本番 g1288 の実測）

軌道待ち伏せで将軍をボス軌道に置いた直後から、**自軍の出撃が味方将軍を攻撃**していた。

- 04:10:37 `どうし vs トレビス`（トレビスは待ち伏せ中の自軍将軍）→ 勝利で wins 25。
- 同様に ピオーネ / ヘパイストス / コリアンダー / ポセイドン / ビシソワーズ など、
  パネルの敵名が自軍将軍名と一致する戦闘が繰り返された。
- この間、`generals_lost` は10名。ボス本体との交戦は1回だけ。

## 原因

出撃（攻撃）の目的地は「ボスセル」だが、そこに味方将軍が立っていると
ゲームは**味方に攻撃を当てる**。`_target_roof_under_marker` は
ボスセルへの攻撃をYジャンプの受領印だけで確定しており、味方の存在を見ていなかった。

## 変更

- `boss_pursuit.friend_on_boss_cell(mem)`: ボス実測セルから±16pxに、
  wave将軍の `unit_world` / `ambush_cell` があるかを判定。
- `map._target_roof_under_marker`: ボス城への攻撃（step が PURSUIT/RECALL 以外）で
  味方がボスセルにいる場合は確定せず、`boss_target_friendly_held` を記録。
  待ち伏せ・帰還の再照準（PURSUIT/RECALL）は対象外。
- `BOT_VERSION` v1287、hot-load許可リストへ追加。

## 検証

- `tests/test_hanjuku_boss_friendly_fire.py`（2件）: 味方検知／攻撃確定の拒否。
- 第9話・追撃・off_chart・台帳 141 passed。

## 期待

- 同士討ちが止まり、将軍喪失が減る。
- ボス本体への攻撃だけが成立する。
