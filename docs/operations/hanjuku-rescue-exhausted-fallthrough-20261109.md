# 半熟英雄: 救済メニューの予算切れ後は通常コマンド判定へ委ねる（v637、2026-11-10）

## 症状（実測 19:3x〜20:0x）

戦闘メニューで **同一 `[b]` プランが414件連続**し、戦闘が進みませんでした。
`action_plan` には**理由が記録されない**（＝記録なしで B を返す経路）ことも確認。

## 原因

`egg_battle_step` の救済メニュー経路で、観測予算（`menu_ticks > 12`）を使い切った後も
`rescue['exhausted'] = True; return [pad('b')]` を**毎回**返していました。
B はこの箱を閉じないため、画面が変わらないまま無限ループになります。

## 修正（v637 `hanjuku-chart-v637-rescue-exhausted-fallthrough`）

- 予算切れの**最初の1回だけ** B を返して記録（`battle_menu_rescue_exhausted`）。
- 以降は `None` を返し、**通常のコマンド判定**に委ねます（未知の行を無制限に確定しない）。

- 戦闘・奥の手・診断系 141件 passed。
