# 未開始の戦闘入場情報を管理画面で解除する

## 実ランで確認した問題

g510-ff48ae57 の1790765038.0609825にジョンリギ防衛告知を認識した後、5054.9096289にmain_menu、5115.375727にhouse_scan_complete（7将軍）を操作した。戦闘は開始されていなかったが、古いattack情報が残り、5130.2691782のヴィーナス対カシュー82/39をジョンリギ防衛と記録した。5174.6732183の勝利82/0より前の5166.0251768にはジョンリギ敵領が観測された。勝利画面frame-021のRGB eb19cc098f3b9818946aa6eadda210b8c8f7996f8df4cd3af0d8523a426dd933 は保存observationと一致し、実HP82/0を目視した。世界地図frame-026はRGB255a3c31886492a191adbcb537acef3b61f870ca9cd3988440548514574d2bedでobservationと一致したが、5166の所有判定そのものとは別フレーム。入場frame-013はリング上書き済みで過去画像の証拠には使用しない。

この証拠で確認できるのは、未開始の告知が管理操作を越えて別の戦闘位置に流用されたこと。ヴィーナスの実戦闘場所、ジョンリギの守備将軍の死亡、城が失陥した直接原因は未分類。

## v107

既知の管理画面（main_menu、城情報・出撃選択、月一・商人、解雇）へ戻り、現在のbattleがない場合だけ未開始attackとbattle_seenを解除しbattle_entry_expiredを記録する。城所有・守備一覧・死亡・勝敗は変更しない。通常map、全体地図、未知・文字表示・戦闘メニューは入場前にも表示されるので解除証拠にしない。活動中のbattleは既存battle_endの2回確認を通し、v104守備交代/v106敗北後所有保持を維持する。

募集50Gを兵士補充より先に確保し、賃金30Gと必要資金を保持する既存処理、採用後実残金再計算、原典札と実携行キャトルミューの扱いは維持する。
