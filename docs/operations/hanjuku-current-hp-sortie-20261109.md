# 半熟英雄: 出撃は「現在HP」で選び、HP0の将軍は送らない（v567、2026-11-09 オーナー指摘）

## 症状（オーナー報告 16:04）

「将軍たちが、卵を一切使わずに負けたりしている」

## 実測

g1163 第7話 2026-11-09 15:37〜16:02 の敗北5件はすべて `battle_result` が
**ally 0**（開始時から0）:

| 時刻 | 突入将軍 | 開始時HP | 結果 |
|---|---|---|---|
| 15:37:25 | キール | 未読 | ally 0 / enemy 15 |
| 15:49:25 | キール | 未読 | ally 0 / enemy 32 |
| 15:53:01 | バゲット | 未読 | ally 0 / enemy 56 |
| 15:55:25 | アルテミス | **hp 1 / 49** | ally 0 / enemy 29 |
| 16:02:42 | リーキ | **hp 10 / 30** | ally 0 / enemy 48 |

HP 1〜10 の将軍を送っていたため、卵コマンドを出す前に戦闘が終わっていました。
`_strongest_first` は **最大HP** で並べており、現在HP 1/49 の将軍が上位に来ていました。

## 修正（v567 `hanjuku-chart-v567-current-hp-sortie`）

- `_current_hp(mem, general)` を追加し、`_strongest_first` は**現在HP**で並べる
  （未読は最大HP、両方未読は名簿順）。**現在HP 0 は最下位**（修理に回す）。
- `_boss_wave_pick` の並びに `dead`（現在HP 0）を追加し、他のどの優先より後に回す。
- 既存の「卵ランク→距離」の順序はそのまま。

## 確認

- `tests/test_hanjuku_strongest_attacker.py`: 現在HP 40 > 10 > 1 > 0 の順になる。
- `tests/test_hanjuku_boss_wave_solo.py`: HP0の将軍よりHP40の将軍がボス波に選ばれる。
- 出撃・ボス波・偵察・チャート 132件 passed。
- 本番反映後: 敗北時の `battle_result` が ally 0 にならず、卵を使う前に終わる事例が
  減ることを実測する。
