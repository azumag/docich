# 半熟英雄: HP1のボスに「一撃フィニッシュ」を使わない（v1341、2026-11-22）

## 症状（本番 g1288 実測）

ボス（せいめいたい HP500）が **HP1** まで減っているのに、3連敗していました。

```
23:35:46 シャルドネ vs せいめいたい  hp 56 / 敵1 → loss
00:32:45 ローズマリー vs せいめいたい hp 98 / 敵1 → loss
00:33:33 マンゴスチン vs せいめいたい hp 85 / 敵1 → loss
```
いずれも `battle_one_hit_finish`（敵HPが一撃で倒せる値なので白兵で押し切る）を
選んでいましたが、**ボスの反撃でこちらが倒れて敗北**していました。

## 原因

`_one_hit_lethal` は「敵HP ≤ EGG_WALL_DAMAGE なら一撃で倒せる」と判断し、
カード・卵を使わず白兵へ進みます。しかし相手がボスの場合、HP1でも反撃で
将軍が倒れます。

## 変更

- `judgment/battle._one_hit_lethal`: **ボス城またはボス名の敵**では False を返す。
  ボスはカード・卵の戦術に任せ、白兵の一撃フィニッシュを使わない。
- `tests/test_hanjuku_one_hit_finish.py` に1件追加。
- `BOT_VERSION` v1341、hot-load許可リストへ追加。

## 検証

- 一撃フィニッシュ・ボスパネル・boss_events・台帳 55 passed。

## 期待

- HP1のボスに対して、バルムンク（在庫があれば）やカード・卵の戦術で
  トドメを狙うようになる。白兵での敗北が減る。
