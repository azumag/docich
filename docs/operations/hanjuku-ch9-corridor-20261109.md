# 半熟英雄 第9話: 一本道の攻略と移動ボスへの再出撃（v568、2026-11-09）

オーナー指示（2026-11-09）: 第9話は城が一本道でしか攻略できず、ボス城（完熟兵器 P）が移動する。
第9話だけ出撃計画を専用にする。

## 道順（公開資料由来・ゲーム内は未実測）

`hanjuku_chart.CORRIDORS[9]`:
アルマムーン → ハヤク → タオ → サヌト → オシロガ → ドンドン → オオキク → ナッテ → シマウ → カラ → イソ → イデ！

- 根拠: [GCGX 第9話](https://gcgx.games/hanjuku/09.html) の「黒いところは進入不可なので、くねくねしながら１本道を進軍する」
  と、城名を順に読むと「早く倒さぬとお城がドンドン大きくなってしまうから急いで！」になるという記述。
  城名の並びがそのまま道順という推定。
- ステージマップ画像（130px）の壁を塗りつぶした解析は、ナッテまでこの順と一致し、それ以降は薄い壁が潰れて漏れた。
  末尾（シマウ・カラ・イソ・イデ！）は実走で最初に確かめる。
- 旧 `CHAPTER_9_ORDERS` はサヌト→ドンドン、ドンドン→ナッテ、オオキク→シマウ が途中の城を飛ばしていた。道順に直した
  （第9話は機械攻略になり、この表は `all_orders` / 旧チャート復帰用）。

## 攻略の規則（機械攻略）

- 狙うのは道順の次の城だけ。途中で奪われた城は再び「次の城」になる。
- 出撃元は隣接する自城だけ（`routes.legs(9)`、第3話の道路表と同じ仕組み）。直線の行軍ブロック判定は第9話では無効。
- 距離は道順の手数（`_distance`）。後方の将軍は一城ずつ前線へ送る（第3話と同じ中継移動）。
- 第9話のみ「守備を残す」規則を外す（`chart.guard_free`）: 城の最後の1人も出撃可、主人公の城のガード不要、
  空城の補充なし。**ゲーム側の制約ではないとオーナーが明言**（コード内の旧コメント「ゲームが拒否する」は
  実測の裏取りなし）。後方は前線の背後にあるので空でも落ちにくい、というオーナー確認（2026-11-09）が前提。

## ボスと野営

- ボスのセルは v536 の Y ビュー ドクロ実測のみ（`chart.moving_boss_cell`）。固定座標なし。
- **ボス段階**（道順の全城が自軍）になってから、第9話の野営は自城へ戻さない（月次巡回も帰還タスクを積まない）。
  それ以前の野営（敗走など）は従来どおり自城へ帰還させる。
- ボス段階でドクロのセルが新しいときは、テントの `いどう` を選び、Yジャンプでボスのセルへマーカーを合わせて確定する
  （`recall.boss_redirect_goal`）。ドクロが無い間は野営したまま待つ。
  Yジャンプの受領印（`y_jumped['RECALL']`）は再出撃ごとに消す（ボス名は毎回同じなので古い印が確認を素通りする）。
- 再出撃の再試行は120観測待ち（失敗が続けば倍々で400まで）。

## 切り札

第9話は旧チャートの対象から外れたが、通常城への出撃には旧チャートの切り札
（ブラッキー/クースカン/ファバード、兵士HP100対策）を持たせる（`card_orders`）。
ボスの波は従来どおり「あるものを持たせる」（切り札指定なし）。

## 未実測（ここが外れたら要修正）

6. ボスの波は出撃元を直線距離で選ぶ（道順の中継はボスまで通っていない）。後方の城から出した波が
