# 半熟英雄: 保留画面のOCR取得量を記録する（v612、2026-11-10）

## 背景（実測）

保留（`situation_held`）の内訳を追ううちに、**画面テキストがまったく読めていない**ことが
分かりました。

- ライブの取得フレームは **299x224**。`parse()` は行（13〜16行）を返すが **spans が空**。
- 同じパーサでも、リポジトリ内の **256x224 フィクスチャ**（`tests/fixtures/hanjuku/g706-resume-card-select.png`）は
  `card_select` として全文が読めます。
- 299x224 のフレームを 256 幅へ最近傍リサンプルしても回復しませんでした。

つまり保留の多くは「画面遷移待ち」ではなく **OCRが0文字**であることが原因の可能性があります。

## 変更（v612 `hanjuku-chart-v612-hold-text-yield`）

`situation_held` の `observed_metric` に **`text_len`（その画面から読めた文字数）** を追加。

## 確認

- 出撃・確認・ボス切り札 228件 passed。
- 本番反映後: `text_len: 0` の比率を実測し、OCR側（フォント照合／取得解像度）の修正を次段で行う。
