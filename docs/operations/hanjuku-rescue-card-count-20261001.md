# 同名の救済札と退却判断（g514 / v118）

基準main: e81ab836。v114の計画再評価、v115の主人公退却経路を保持する。

## 実記録

同一ランg514-8937051b/generation514、v115、I:8577dd:1のフーリック攻撃。

- 12845: バジルHP40/開始40、ビシソワーズHP27。planned_cards=[]、携行期待はイッテツーン2枚。
- 12851: 実札一覧にもイッテツーン2枚。1枚選択を予定し、消費は未確定。
- 12852/12863: 使用告知は未分類、白兵戦へ戻る。
- 12867/12869: 再確認した札が名前単位のcards_attemptedで除外され、救済手段なし扱いになる。
- 12870/12874: HP40対27のまま退却メニューを開き、たいきゃくを選択。
- 12879: 最終HP40対27、cards_selected/unclassified各1、used=[]、結果未分類。逃走成功・勝利は未確定。

この区間に卵戦のdecisionはない。HP閾値ではなく、planned_cards空→unarmed_clash_risk→survival.exhaustedの退却経路と整合する。卵戦のstickyフラグ原因はこの実例では採用しない。

## 修正

実札一覧の同名枚数を選択時に記録する。前回より少ない正の枚数を連続2回読めた場合だけ残る同名札を候補に戻す。選択・枚数変化から使用receiptを作らない。枚数不変、旧状態で枚数根拠なし、カーソルなしではAを再送しない。従来のメニュー観測・試行上限を維持する。

既に試行した札が実一覧に残るが枚数減少が未確認なら、cards_uncertainを記録する。この不明状態だけから健康な一般将軍を「救済手段なし」として即退却させない。危険HPの判断、主人公の卵戦退却、敵ターン待機、退却不可時の上限はそのまま維持する。勝てるという推測はしない。

## 検証・範囲

同名2→1の連続確認、枚数不変で再決定なし、部分的な1枚読みの後に2枚へ戻る場合、カーソルなし、旧状態、危険HPの主人公/一般将軍を回帰で確認。現ランでの自然発火は正規反映後に別途確認する。

募集、先発隊、キャンプ帰還、主人公出撃順位、カーソル速度は本PRに含めない。キャンプ帰還について13318/13476の入力送信は確認したが、実将軍identityと到着receiptがなく成功未確認。
