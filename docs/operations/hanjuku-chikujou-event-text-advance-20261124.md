# 築城中のイベント文送りと遷移待ちの分離

Issue #5274: 章9 13-1で、増築済みの城を照合した後、未試行のイデ！が一覧外に残っていた。築城サブフローが一覧の再観測を待っている間に、全体のイベント文送りが同じ `text` 画面へ A を送り、直後に築城側の有限待ちが尽きて月を終了していた。

## 変更

- 築城サブフローが所有する城一覧、増築確認、増築結果、資金不足の文面は、イベント文送りの汎用 A から保護する。タイプライター更新中でも、選択中の城を誤って確定しない。確認文の片側だけが現れた途中表示と、城名/レベルだけが現れた結果の途中表示も保護する。
- 築城サブフロー以外のイベント会話は従来どおり有限回で A を送る。
- その A はイベント会話への入力なので、築城画面の遷移待ちカウンタをリセットする。会話の進行を築城一覧の停滞として数えない。
- 実際の築城選択・確認は既存の画面認識、所有城、価格、残金、支払証拠のゲートを維持する。

回帰テストは、築城一覧/確認/結果の自動 A 抑止と、無関係なイベント会話を送った後の待ちカウンタ再開を検証する。実機でイデ！が増築されることは別途受入確認が必要。
