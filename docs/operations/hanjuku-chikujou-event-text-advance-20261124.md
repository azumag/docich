# 築城・ドーム型野営中のイベント文送りと遷移待ちの分離

関連Issue: #5274、#5312。

## 築城 (#5274)

章9 13-1では、増築済みの城を照合した後、未試行のイデ！が一覧外に残っていた。築城サブフローが一覧の再観測を待っている間に、全体のイベント文送りが同じ `text` 画面へ A を送り、直後に築城側の有限待ちが尽きて月を終了していた。

- 築城サブフローが所有する城一覧、増築確認、増築結果、資金不足の文面は、イベント文送りの汎用 A から保護する。タイプライター更新中でも、選択中の城を誤って確定しない。
- 築城サブフロー以外のイベント会話は従来どおり有限回で A を送る。
- その A はイベント会話への入力なので、築城画面の遷移待ちカウンタをリセットする。
- 所有城、価格、残金、支払証拠のゲートは変更しない。

## ドーム型野営 (#5312)

ch10 17-4では、ドーム型野営を開いた後に防衛告知の `text` 画面が現れた。帰還フローは未計測画面として有限回待ち、最後に B で閉じる設計だったが、汎用イベント文送りが3観測後に A を送り、その後に `camp_group_screen` として帰還を取り消していた。

- `recall_dialog` が所有する `stage=menu, camp_kind=dome` の `text` だけをイベント文送りから保護する。
- 既存の `DOME_SCREEN_WAIT` と B による閉鎖をそのまま使い、未知の画面で盲目的に A を送らない。
- 通常テント、砦の各段階、コンサート、帰還フローが所有しない会話は従来の有限イベント送りを維持する。

回帰テストは、築城画面の所有権、ドーム帰還中の防衛テキスト抑止、既存の有限B閉鎖を検証する。実機で帰還が成立することは別途 runtime 受入確認が必要。
