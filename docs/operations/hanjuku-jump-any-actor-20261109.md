# 半熟英雄: 計画の再生成で将軍が変わっても出撃元への移動は続ける（v616、2026-11-10）

## 症状（実測）

v615（同一将軍ならジャンプ継続）を反映しても
`castle_jump_failed(why=order_changed, phase=menu, age=1)` が **25分で7回**。

## 原因

チャートworkerは**再生成のたびに将軍も選び直します**（例: シュゼット→しまばら が
マンゴスチン→しまばら に差し替わる）。v615 は「同一将軍」を条件にしていたため、
将軍が変わると中断していました。

## 修正（v616 `hanjuku-chart-v616-jump-any-actor`）

**出撃元と出撃先が同じ**なら、将軍が変わってもジャンプを継続します。
城に着いてから別の将軍が出撃することは、オーナー指示（2026-11-10「計画と違う将軍でも
かわりを出撃OK」）の範囲内です。

## 確認

- `tests/test_hanjuku_castle_jump.py` の該当アサーションを新契約へ更新。
- ジャンプ・カーソル・チャート・出撃優先度 154件 passed。
- 本番反映後: `castle_jump_failed(order_changed)` が消え、出撃が成立することを実測する。
