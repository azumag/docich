# 半熟英雄: ボス接触時に将軍の実位置も記録する（v1286、2026-11-21）

## 背景

v1280/v1281 で `unit_world`（追撃Yジャンプ起点の実位置）が取れるようになり、
いどう後に将軍が軌道セルへ**1セル以内**まで移動していることを実測した
（03:50 トレビス [684,516] → 03:59 [716,600]、狙い [722,605] と差 6,5px）。
一方、`boss_ambush_contact`（ボスが待ち伏せセルに到達）は起きても交戦に
ならないケースがあり、接触時に将軍が本当にそこに居たのかを記録していなかった。

## 変更

- 追撃の redirect で `entry['unit_world']` を保存。
- `boss_ambush_contact` の記録に `unit_world` と `unit_dist`（ボス実測セルとの差）を追加。
- `BOT_VERSION` v1286、hot-load許可リストへ追加。

## 検証

- `tests/test_hanjuku_boss_ambush_track.py` に1件追加。10 passed。
