# 半熟英雄: ボスセルをYビューのドクロから全章で実測する（v538、2026-11-09）

## 背景

v536 で第9話の移動ボスをYビューのドクロから実測して解禁しましたが、対象を第9話に
限定していました。しかし同じドクロ sprite は第3話のボス、第4話の4地点にも使われており、
**近似セルしか持たない章（7・8・10・11・12話は公開マップの旗から推定）**でも
Y ビューから正確なセルを測れます。

## 変更（v538 `hanjuku-chart-v538-y-view-boss-cell`）

- `hanjuku_chart`: `set_boss_cell(chapter, cell)` を追加（`moving_boss_cell` は別名）。
  `castles(chapter)` は実測セルがある章だけ `ボス` を実測値へ差し替える。
  **受け付けるのは近似セルの章（6・7・8・9・10・11・12話）だけ**。1〜5話は既に実測済みの
  セルを持ち、ドクロ由来のセルは城タイルから最大2タイルずれ得る（第4話の4地点で実測）ため、
  実測値を上書きしない。
- `os_layer/world._apply_skull_boss`: 章4以外のYビューでドクロが**1つだけ**・
  **2回連続一致**のとき `boss_cell = {chapter, cell, tick}` を記録（`boss_cell_measured`）。
  章4は4地点を `_apply_season_sites` が読むため対象外。
- `orchestrator.decide`: `boss_cell` を毎判断で chart へ登録。**第9話（移動ボス）だけ**
  `MOVING_BOSS_TICKS`（1200観測）で失効、静的ボスは章の間ずっと有効。
  章が変わった実測は無視。章替わりで `campaign` が `boss_cell` を消す。
- 章4の4地点読取・第5話のWRAM実測セルなど既存の値は、実測が無い限り不変。

## 安全性

- ドクロが0個/2個以上のフレーム、範囲外セルは登録しない（従来の近似セルのまま）。
- 実測は2回連続一致のみ。章が違う実測は使わない。移動ボスのみ失効する。
- 既存の `set_moving_boss_cell` / `_apply_moving_boss` は別名として残し、呼び出し互換。

## 確認

- `tests/test_hanjuku_moving_boss.py`（18件）: 第3話→(306,141)、第4話4地点→登録セル、
  近似セルの差し替えと解除、不正値、ボス注文の解禁、2回一致、位置変化、章4は対象外、
  静的章は古い実測を保持、移動ボスは失効、他章の実測は無視、`decide` の同期。
- チャート・ボスセル・層・状態 444件 passed（`test_hanjuku_diagnostics` の43 errors は
  ローカル pytest 7.4.4 の `setup()` 非互換で、CI の 9.1.1 では実行される）。
- 実機の第7話以降で `boss_cell_measured` が出るか、出ない章で近似セル+探索候補
  （v531）が機能するかを実測する。
