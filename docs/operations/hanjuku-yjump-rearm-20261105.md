# 位置が固まっている間はYジャンプの総量上限を戻す（v436、2026-11-05）

## 症状（実測）

第6話でボス出撃が止まったまま。

- **歩き**: `cursor` が [392,144] のまま、`nav_last` も null で位置推定が凍結。
- **Yジャンプ**: v426 の総量上限（指示・画面モードごとに18回）を使い切っており、
  `y_jump_last` のブロックが明けても Y を押せない。

- 上限そのものは維持（固まっていない限り再武装しない）。
