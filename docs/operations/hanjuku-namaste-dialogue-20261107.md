# 半熟英雄: 卵回復のナマステ会話の入力保留を修正（v504）

## 実測

2026-11-07 JST、g1147/v502 の卵回復中、18:37:07 → 18:37:13 →
18:37:19 と約6秒間隔で `event_text_advance` による救済Aが発生した。
通常の処理は入力を保留し、同じ文を3観測して初めて救済されていた。
正規read-only診断は [run 42360596253](https://github.com/azumag/docich/actions/runs/42360596253)。

対応する保存フレームを `g1147-priest-namaste.png` として固定した。
RGB digest は `e9ca5d1bbb17579b79be76d3959df9d843070c0e584fbb7175f20fe9dc1a6188`。
メッセージは「ナマステ！」だけだが、僧侶の絵が手カーソル
`(116,82,137,96)` に一致する。さらに会話枠の下の送り印が
`y=207, x=120/128` の未読文字2セルとして残っていた。
既知の僧侶の絵とも完全一致せず、通常会話の判定から外れていた。

## 修正

- 既知の僧侶の絵に今回の実測variantを追加する。
- 既知の僧侶が表示された文脈で、送り印の小領域が実測fingerprintと
  一致した場合だけ、その2セルの未読表示を除く。他の未読文字は保持する。
- 通常の卵回復と保存再開の会話送りで、既存の厳密なナマステ本文判定を使う。
  僧侶の絵だけが異なる場合でも、この既知の文だけは最初の判断で進める。
- 購入確認・費用・不明な本文・別カーソル・戦闘文脈は会話に昇格させない。
  回復完了・支払い・卵残数は従来どおり別の観測で照合する。
