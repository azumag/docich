# 主人公の出撃後順位 v122

Base: `12cb0e8df0d4c3e17d63b2ccd7dc6e8a6f28fa90` (v121).

ユーザーは、主人公の敗北がゲームオーバーになるため、他の将軍で代替できるときは主人公の出撃を後回しにすることを指示した。ボス攻略も対象とし、手動操作で回避しない。

## 確認した固定経路

`deploy_step` のボス専用分岐は `order.general` だけを選び、`general_override` と `order_context` を消していた。`_deploy_context` はボスの実将軍を計画将軍へ戻し、`target_step` も計画本人との一致を要求していた。一般の主人公出撃も、本人が見えれば他の待機将軍より先に選んでいた。

## 修正

- 主人公が計画された攻撃は、出撃元の実一覧で読める、同版名簿に存在する、行軍中でない仲間を先に選ぶ。一覧順を保ち、能力や勝利を推測しない。明示された主人公以外のチャート役割は保持する。
- 元の出撃城に仲間の記録があるなら、主人公の別城へ追従する前にその城の実一覧を確認する。古い駐留記録は確認開始の根拠にしかせず、出撃Aの証拠にはしない。
- 名前の重複、未知名、部分OCR、本人またはカーソルが読めない一覧では選択しない。既存の守備・奪還重複・最後の城・未確定出撃照合を先に適用する。
- 代役の一覧選択Aは未確認入力。切り札/携行確認の実将軍名を、既存の出撃status配置（名前x16..80、しょうぐんx80..128、y31）で再照合する。不一致なら取消、読取不能なら3回まで再観測後取消とし、無限待機や名前だけの差替えをしない。
- 携行確認後の実本人は、overrideや計画が変わっても `order_context.actual_general` と選択記録の一致で保持する。行軍、実ボス入城、戦闘の本人へ接続する。既定ボス札と既存使用戦術は維持する。
- 主人公の破損/第1話の卵消耗ガードは実際に主人公を選ぶ時に維持する。仲間の記録があれば一覧確認へ進めるが、実一覧に代役がいなければ主人公の回復待ちに戻る。
- v121募集とv120卵修理の予算/receiptは変更しない。保留PR1465/controller機能への依存はない。
