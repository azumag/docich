# 半熟英雄: 優勢な白兵戦では卵を温存する（2026-10-15）

## 目的と変更

オーナー指示「どう考えても有利なのに卵を無駄に使う」を受け、現在の戦力差より開幕HPの割合や切り札の有無を優先していた温存判定を修正する。

一般将軍は、同じruntime/generation/leaseと交戦将軍・開幕HPに束縛された戦闘で、現在HP、現在兵数を加えたHP、本人の戦闘値を掛けた戦力がすべて敵の2倍を超える場合、開幕HPが最大の70%以下でも卵を温存できる。例えばゼウス55/85、敵クミン5、兵5対0の合成状態は、HPの割合だけで卵を使わない。開幕時に敵の損耗を見ていない場合は `enemy_progress=not_observed` と記録し、ダメージや勝利を捏造しない。

戦闘中に自軍HPが減った場合は、従来どおり敵HPまたは現在兵数が開幕から減った観測を要求する。自軍だけが一方的に損耗している戦闘は、静的な戦力差だけで温存を続けない。

主人公は最大HPの70%を超える健全な状態と、HP・兵込みHP・戦闘値込み戦力が全て敵の2倍を超える余裕がある場合だけ、切り札がないことを理由に卵を使わない。主人公の劣勢検知・ゲームオーバー保護は維持する。

## 変更しないこと

HP12以下の救済、敵召喚、ボス、不明・古い・不正な兵数やHP、別ランの記録、進行中の救済札は温存の追加許可にしない。将軍の価値に応じた退却修正 #2287 と切り札の実使用証拠契約を維持する。卵を選択しただけで残数を減らしたり、選択を実消費と断定したりしない。

既に実メニューで温存を選んだ局面は、次の完全パネルでも優勢を再確認できる間だけ「退却前に卵を確認する」経路の再オープンを抑える。未確認の資源検査を飛ばす許可ではなく、危険時には従来経路へ戻る。

閾値はゲームのダメージ式や勝率ではなく、戦略上の保守的な比較値である。
