# 半額の行商人で、未読在庫の目標札も買う（v1459、2026-11-24）

## 症状

行商人（半額の中華商人）に **ミックミー20G** が並んでいても購入されず、
クースカンばかり買っていた（g1342 6-8）。購入順をミックミー優先にしても
（v1458）、この状態では購入されない。

## 原因

`plan_bargains` は在庫台帳（`card_stock`）が**未知**の札を買わない
（owner 2026-11-22: 未知を0とみなした99枚要求が拒否ループになるため）。
一方このランでは第4話のカード全量読み（card census）が
`observation_limit` で2回中断し、`card_census_disabled[chapter=4]` が立っていた。
そのため一度も所持していない ミックミー は永久に未知のままとなり、
実一覧に並んでいても購入対象にならなかった。

## 修正（v1459 `hanjuku-chart-v1459-merchant-listed-unknown`）

- **半額の行商人（`cheap_vendor`）の実一覧に価格付きで並ぶ目標札**に限り、
  在庫が未知でも目標数（`BARGAIN_TARGETS`。ミックミーは2枚）まで購入する。
- 一覧の無い暫定パス、通常の月次商人、余剰資金の99枚要求は従来どおり
  未知の札を買わない（owner 2026-11-22 の規則を維持）。
- 目標在庫・価格上限・月次200G/8枚・99枚上限の規則は不変。
