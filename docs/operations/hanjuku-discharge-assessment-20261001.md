# 強制解雇の未評価決定を保留する

ユーザーは賃金が収入を超えた際も強力・重要な将軍を保護するよう指示した。
既存 `discharge_step` は非負の所持金ヘッダを読めないと、候補の能力・役割・
負債額・解雇後収支を評価せず既定カーソルへ A を送っていた。

v116 はこの A を削除し、`discharge.status=assessment_required` と未確認の理由を
状態へ保存する。同月の同状態は再通知せず、月が変わると一度再記録する。
旧版の解雇会話へホットロードした場合も過去の `held` や決定回数で新ガードを
飛ばさない。古い `house_eggs` は解雇候補の価値や実在の根拠にしない。

非負の所持金を実読できた時の既存の有限 B 退出は維持する。負債時の B 退出は
未検証であり、入力しない。現時点では安全な候補評価・能力取得手順も未確立の
ため、明示的な判断待ちで止まる。これは解雇選択完成や収支改善の完了ではない。
次の作業で実候補の能力/卵/内政/チャート役割、実負債と解雇後収支を照合する。

回帰は未読所持金・月ヘッダ欠落・旧会話への自然ホットロード・古い破損記録・
繰返し観測で A/B を出さないことと、非負残金の B 退出を検証する。
v114 の採用計画再評価と v115 の同戦闘主人公退却接続を保持する。
実ゲームでの解雇/退却発火はこの変更では実施・確認していない。
