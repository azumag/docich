# 半熟英雄 第9話ボス段階: 交戦が成立しない要因の実測（2026-11-15）

## 目的

第9話のボス段階（全12城確保後、完熟兵器Pが移動）で、ボスへの出撃が
「入城」せず交戦が成立しない問題の、ローカル headless 実測を記録する。

## 実測した事実

- **ボスセルは毎月動く**: Y ビューのドクロから実測したセルは、月相当（約300〜600観測）で
  大きく変わる（例: `[866,373]` → `[690,181]`、`[730,373]` → `[874,413]`）。
  `y_view_skulls` の色許容と赤目 pupil 対応、同じY訪問内2回一致は v880 で導入済み。
- **ボス出撃は入城しない**: `boss_sortie_overdue` が `marching` 2400〜6553 で繰り返し発火。
  出撃元の在城将軍は既におらず（`source_still_has_general: false`）、再出撃を繰り返しても
  ボス城（実測セル）へ入らない。
- **将軍は出撃元の城の近くで野営する**: `camp_found` の `boss_redirect` 例で
  `camp_world [532,835]`（カラ `[504,864]` の近傍）。東のボス領域まで行かず、
  出撃元近くでキャンプに戻るケースがある。
- **ボス段階で自城帰還が混ざっていた**: 道制圧前に開始した帰還 state が home のまま残り、
  可視自城（サヌト）へ帰還していた（225939/226035/227800）。v885 で boss redirect へ
  変換するよう修正済み（`camp_boss_redirect_adopted` / `camp_boss_redirect_held`）。
- **野営は画面に入らない時間が長い**: ボス段階の地図フレームでは `camp_hunt`
  （野営が見えない）が続く。月次のステータス巡回が長く、フィールドでカーソルを
  動かす時間が少ないため、可視野営からの再出撃の機会が少ない。
  `mem["cursor"]` は 2000観測以上 `[389,884]` のままの窓もあった。

## 仮説（未検証）

1. ボスセルの Y ビュー→セル変換は城の旗読み（`WORLD_MAP_OFFSET`）と共通で、城ジャンプの
   成功から大きくは外れていない。ただし赤目ドクロのスプライト基準点が第3話の黒目ドクロと
   数 px 違い、攻撃先が 1〜2 セルずれる可能性は残る（セル `[866,373]` と `[690,181]` の
   直接の 16bit x,y ペアは WRAM/SRAM に見つからず、逆解析は未完了）。
2. 通常の出撃（目的地ピッカー）は非城セルへの行軍を受理しても、到着時に部隊が
   野営するだけで「入城」イベントにならない可能性。設計上の意図は野営メニューの
   `いどう` でボスセルへマーカーを合わせる経路（docs/operations/hanjuku-ch9-corridor-20261109.md）。
3. 野営の再出撃は「可視野営」が前提で、野営を画面に出す focus/探索が不足している。

## 次に必要なこと

- 野営の再訪: 既知の `camp_world` へフィールドカーソルを寄せてテントを画面に入れる
  （`camp_hunt` の記録と `recall_verification.camp_world` を使う）。
- ボスセルのスプライト基準点の較正（赤目ドクロの中心とセル変換の再測定）。
- 非城セル出撃のゲーム側の挙動（入城イベントの条件）の実測。
- `しろ` 一覧のスクロール条件（手が最下行のときページ送り、月次フローでは確認済み）の
  城ジャンプ側への適用。
