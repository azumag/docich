# 半熟英雄: ボス軌道を密に測る（v1279、2026-11-21）

## 背景（オーナー指示 2026-11-21）

「9話のボスの軌道と、どれくらいで一周するかは、ROMを解析してください」
「そもそも全然軌道上に配置できてない」

## ROM解析の状況

- 1MB ROM（`games/roms/hanjuku-hero.sfc`）内を、実測セル（`[818,853]`
  `[874,229]` `[690,181]` など）の16bit/8bit座標ペア・交互座標テーブルとして
  走査したが、軌道テーブルは見つかっていない（座標系も view px / field px /
  tile のいずれか未確定）。静的な表ではなく移動処理側で持たれている可能性が高い。
- 実測トラック16点では、南 y≈629〜853 と北 y≈173〜373 を往復し、南→南の
  間隔は約3050 tick（≒50分）。現行の待機1時間はこの1周をカバーする。
