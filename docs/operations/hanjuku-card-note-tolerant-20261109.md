# 半熟英雄: 切り札一覧の説明行の1文字欠けでパネル全体を捨てない（v621、2026-11-10）

## 症状（実測 07:4x）

「切り札一覧の名前・数量・配置またはカーソルが実測構造と一致しないため保留」が
**1時間で15件**。実際の読み取りはこうでした。

```
160,55 ダイチスイム 2      160,71 ブラッキー 99
160,87 フットバース 99     160,103 ダンスライン 99
136,127 バトルよ           176,127 のきりふだです   ← 「う」だけ欠落
```

## 原因

`_measured_card_select` は説明行（y=127）を
`'バトルようのきりふだです'` と**セル完全一致**で検証していました。
OCRが1文字（「う」）を落とすと**パネル全体が不読**になり、保留→出撃取消になります。
この行は**静的な見出し**で、データではありません。

## 修正（v621 `hanjuku-chart-v621-card-note-tolerant`）

説明行は **`バトル` で始まり、10文字以上、UNKNOWN を含まない**ことだけを要求します。
カード行（名前・在庫・カーソル）の厳密検証は従来どおりです。

## 確認

- `tests/test_hanjuku_sortie_evidence.py` に1件追加（1文字欠けでも4行読める）。
- 切り札・出撃・ボス切り札・診断 227件 passed。
- 本番反映後: 切り札一覧の保留と出撃取消が減ることを実測する。
