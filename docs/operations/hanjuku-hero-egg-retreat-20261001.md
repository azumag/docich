# 主人公の卵戦コマンドから既存退却判定へ接続する

同じg514-8937051b/gen514/v114の限定SSH読取で、けっかいの攻撃戦を確認。
実入場のbattleはA:8a1a091c:K2、どうし34HP/開始90/最大90、クイーン70。
予定クースカン/ノリウツールは未選択・未使用だった。
18:15 UTC頃の配信実画面報告も赤旗どうしHP34/青旗ヒュドラ396を示す。
敵ヒュドラ技メニューはowner=enemyとして既存コードが待機していた。

既存egg_battle_stepは実将軍HPを更新しても、卵が使用可能ならuse_eggへ進み、
半HP以下の主人公の既存_hero_retreat_openを呼ばなかった。
action=attackかつ予定札なしの限定probeも、未使用の予定札2枚のため実行されない。
退卵は戦闘からの退却ではない。

v115は自軍egg_battle_menuに表示された主人公の実HP、正常な最大/開始HP、
同じ攻撃のstep/城/本人identity、away=0を要求して既存退却判定を先に試す。
通常battle_menuへ戻って実際のたいきゃくとカーソルが読めた時だけ既存経路が選択する。
戻れない場合は既存3回上限でBを止め、選択不可も既存fallbackへ戻す。
敵技メニュー・一般将軍・不明HP/開始HP・別attack・防衛は変更しない。

このランは修正前のv114で自然にボス撃破へ到達した。
1790792446.3610373 / decision_id g514-8937051b:514:11024:
どうし34/クイーン0、battle_result resulting_event=chapter_1_boss_defeated、
hero_retreat_selected=false。退却成功や死亡を推測しない。
ナキューメラは10663/10669等でworld_map_owners=own、
出撃10291のv114計画Aとinput_sentもdecision_idが一致した。

回帰は予定札未使用/卵可用でも退却probeへ進むこと、正常メニュー実選択、
ボス等で退却不可/戻れない時の有限終了、一般将軍/古いHP/敵メニューの拒否。
実ランでのv115退却発火はcanonical配備後も未確認。
募集人数・主人公先発順位は別変更として扱う。
