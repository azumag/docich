# 半熟英雄: 奥の手・召喚メニューの試行上限を使い切ったら同じ戦闘では再入しない（v633、2026-11-10）

## 症状（実測 18:5x〜19:0x）

1つの戦闘で **`battle_okunote_summon_unconfirmed` 887件** と
**`..._exhausted` 887件** が20分間に記録され、戦闘が進みませんでした
（エージェントは1.5秒周期で回り続けるが画面は変わらない）。

## 原因

上限到達時に「以後は通常のコマンド判定へ戻す」として `None` を返しますが、
通常判定から**同じ召喚メニュー経路へ再入**し、カウンタが0から再開していました。
結果、上限3回→解除→再入を延々繰り返します。

## 修正（v633 `hanjuku-chart-v633-okunote-exhausted-latch`）

- 上限到達時に `cur['okunote_summon_exhausted'] = True` を**その戦闘にラッチ**。
- 以後その戦闘では召喚メニュー経路に入らず、通常のコマンド判定に委ねます。

## 確認

- `tests/test_hanjuku_okunote_exhausted_latch.py` を追加（ラッチ後は再入しない）。
- 奥の手・戦闘・診断 85+1件 passed。
- 本番反映後: 同一戦闘での `_unconfirmed`/`_exhausted` の多発が消え、戦闘が進むことを実測する。

## 追加（v634）: 残った奥の手メニューは確定1回で閉じる

v633 のラッチ後、`おくのて` メニューは**Bでは閉じない**（g1097 の既知挙動）ため、
ボットは B を押し続け、決定記録も出ないまま戦闘が止まりました（19:1x に数分間の無記録）。

上限到達後は**ハイライト行を1回だけ確定（A）**してメニューを閉じ、以後は通常の
コマンド判定に戻します（`battle_okunote_exhausted_confirm` を記録）。
