# 半熟英雄: ドクロが消えた四季王地点を撃破済みとして扱う（v1473、2026-11-24）

## 症状（g1342、第4話）

倒したはずの四季王の城へボス出撃が出続けた。オーナー確認: 倒したのは北東で、
ゲームが示す撃破の証拠は「Y ビュー（全体マップ）からドクロが消えること」だけ
（戦闘後の台詞は無い）。21:11〜21:15 の北東戦は決着が台詞に替わるため敵 HP 0 を読めず
`boss_victories` に入らなかった。さらに旧読み取りは、ドクロが無く地形でもない箱を
「読めない」として前回の open を保持していたため、北東は open のまま残った。

## 実測（g1342 21:20 の Y ビュー、256x224 に resize して読んだ値）

| 地点 | light（ドクロ明色の画素数） | 判定 |
|---|---|---|
| 北西 | 25 | 完全なドクロ（生きている王。ブカティーニが向かっている） |
| 南西 | 25 | 完全なドクロ |
| 南東 | 8 | ドクロの一部（部隊の顔の後ろ）。撃破の証拠ではない |
| 北東 | 0 | ドクロ無し（自軍のキャンプ） |

地点の位置は第3話ボスのドクロ (101,63) を基準に、地点セルの差分×8で求める。
299 幅のスクリーンショットをそのまま渡すと座標がずれるため、必ず 256x224 に
`Frame.resized` してから読む（ボットの実経路は resize 済み）。

## 変更

- `readers.season_site_readings`: 各地点を `skull`（light>=15）/`closed`（地形のみ）/
  `hidden`（light<=2 かつ地形でない）/`ambiguous`（その中間。ドクロの一部）に分類し、
  フレーム健全性 `healthy`（確定読みが2地点以上、かつ完全なドクロが1地点以上）を返す。
  `season_sites()` の戻り値（`open`/`closed` のみ）は従来のまま。
- `world._apply_season_sites`: `hidden` が **healthy なフレームで連続3回**（`SEASON_SITE_HIDDEN_CONFIRM`）
  続いたときだけ `closed` にする。ドクロが読めた時点で連続は途切れ、`skull` が2回続けば
  `open` に戻る（有界・可逆）。`ambiguous` は状態を変えない。`season_sites` の各行に
  `marker` / `light` / `terrain` / `last_read_tick` / `hidden_streak` / `ambiguous_streak` /
  `unreadable_streak` / `frame_healthy` を持たせ、`season_site_marker` 記録で遷移を残す。
- `orders._boss_target_unlocked`: ドクロの見えない地点（`hidden`/`ambiguous`/`unreadable`）は、
  他にドクロの見える地点が残っている間はボス order 候補にしない。見える地点が尽きれば候補に戻る。
- 方角はハードコードしない（4 地点すべて同じ規則。テストは 4 地点で回す）。

## VM 反映後の受け入れ基準

- 新規ボス order_start は、ドクロが見える地点へ向かう。
- ドクロが隠れた地点へは、見える地点が残る間 order_start が出ない。
- 直接証拠（healthy なフレームでの連続3回のドクロ消失、地形のみの読み、HP 0 の勝利）なしに
  `season_site_closed` が出ない。`season_site_marker` の `light` が実フレームで 25 前後
  （完全なドクロ）で読めていることを最初に確認する。light が常に 6〜14 なら暗いフレームを読んでおり、
  閾値（15）を見直す。
- 北西・南西への出撃が実際に launch して戦う。

## 可逆性と野営（オーナー追加確認 2026-11-24）

撃破された王のドクロは消える。一方、自軍の野営放置が生きている王のドクロを隠すこともあり、
野営が解消されればドクロはまた見える。このため hidden→closed は常に可逆に保つ。

- closed が書くのは `season_sites` の行だけ。plan の step を done/dropped にせず、`boss_victories`・
  `boss_defeated` も書かない（これらは従来の HP 0 実測経路のみ）。`_site_king_down` を使う各所
  （orders / replan / policy）は毎回 `season_sites` から再計算する。
- 機械ボス計画は closed 地点を計画から外して作り直されるため、ドクロが再び読めて open に戻ったとき
  `world._restore_site_step` がその地点の step を採用中の機械計画へ戻す（`season_site_step_restored`）。
- 自軍の旗（オレンジ）が箱にあるときは `hidden_with_camp` と `camp` 画素数を状態と記録に残す。
  理由の可視化だけで、判定規則は変えない。

## カーソルはドクロではない（v1476、2026-11-25 00:24）

オーナー確認: 北東と北西の両方が撃破済みで、生きているのは南西と南東だけ。00:24 の Y ビューでは
カーソル（青い四角・白い G・オレンジの角）が北西の箱に乗っており、その黒縁と白画素が
「ドクロの明色」として数えられて light 24 と読まれた（カーソルを渡さずに測った場合）。

- `season_site_readings` はドクロを形で照合する（chapter 3 ボスのドクロ 8 行、明25セル・黒縁25セル）。
  明12以上・黒縁12以上・形の外の明画素4以下で `skull`。明2以下・黒縁8以下で `hidden`。
  青いカーソル塗り（0,64,189）が20画素以上なら `cursor`。残りは `ambiguous`。
- 実測（明/黒縁）: 完全なドクロ 25/25、00:24 南西（将軍の顔が重なる生きている王）15/19、21:20 南東（部分）8/20、
  00:24 北西（カーソル）5/0（形の外の明画素 19）、撃破済みの箱（旗のみ）0/4。
- `cursor` の箱は状態・marker・連続数を変えない（`cursor_streak` だけ増える）。本番ではサーベイが
  `world_cursor` をすでに渡しており、カーソルに重なる箱は読み取りから外れる。
- カーソルが長く同じ地点に乗ると、その地点の古い `skull` は証拠にならない。最後の読みが 1500 tick より古い
  `skull` は「見える」に数えず、最近読めた他地点のドクロを優先する（新しいドクロが他に無ければ従来どおり）。
- カーソルを地点から動かす案は採らなかった。Y ビューのカーソルはゲーム自身の自位置/選択位置の印で、
  `world_cursor`・`map_cursor` の追跡に使われている。実フローでの検証なしに有限回の移動を足すと
  位置追跡を壊す危険があるため、読めない箱は据え置き（unchanged）にする。
