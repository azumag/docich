# 半熟英雄: 増援は「いちばん薄い城」から回す（v592、2026-11-09）

## 症状（実測）

g1163 第8話 2026-11-09 21:33:19、ながはま が陥落。
失陥記録（v576/v582 で追加した `castle_lost_observed`）は
`garrison: ['アテナ'], garrison_known: true, enemy: キッシュ` ——
**守備が1人だけ**の城で、その1人がそのまま敗れていました。

## 原因

`_garrison_rotation` は増援先を **敵城までの距離順**（`plan[c][0]`）に並べていました。
そのため「1人しかいない城」が、余裕のある近い城より後回しになることがありました。

## 修正（v592 `hanjuku-chart-v592-garrison-deficit-first`）

増援先の並びを **不足数（`want - 現在の人数`）の大きい順 → 敵距離 → 城名** に変更。

- 1人の城（不足2）が、2人の城（不足1）より先に増援されます。
- 送り出し元の条件（2人以上・床を割らない・未読の城も可）は従来どおり。
- 1計画あたりの移動数上限（`GARRISON_ROTATION_LIMIT=3`）も従来どおり。

## 確認

- `tests/test_hanjuku_garrison_deficit_first.py`（新規）: 薄い城が最初の増援先になる。
- 本番反映後: 守備1人の城が減り、`castle_lost_observed` の発生が減ることを実測する。
