# 半熟英雄: 波状攻撃の出撃元を「目的地に近い城」から選ぶ（v620、2026-11-10）

## 症状（実測 07:00〜07:20）

しまばら攻撃は **あるまむーん（136,912）から約753セル**で、実測レート3.2/セルだと
**約40分**の行軍。一方 **まつやま（504,128）は336セル**（約18分）。
2時間で `order_start` 6回に対し戦闘3回でした。

## 原因

`_wave_pick` は出撃元を `(家城かどうか, 名前)` で並べており、**距離を見ていません**でした。
そのため波状攻撃は常に家城から出て、長い行軍を払っていました。

## 修正（v620 `hanjuku-chart-v620-wave-nearest-source`）

出撃元を **目的地までの距離昇順**で選びます（同距離なら家城→名前順）。
「城を空にしない」`sender_min`、実測された道（`routes.allowed`）、既に出撃・移動で
予約済みの将軍の除外は従来どおりです。

## 確認

- `tests/test_hanjuku_boss_wave_solo.py` に1件追加（近い城から出る）。
- 波状・計画・出撃優先度・診断 800件相当のうち 448+9件 passed。
- 本番反映後: しまばらへの行軍時間が短くなり、`attack_observed`／`battle_result` が
  増えることを実測する。
