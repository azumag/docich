# 半熟英雄: 城の駐留が空なら野営回収へフィールドを渡す（v1308、2026-11-21）

## 症状（本番 g1288 13:0x の実測）

- `world.garrison` が **イデ！に どうし 1名だけ**、他の11城は空。
- 出撃は `order_failed: 移動元の将軍が1人以下のため移動を取り消す` で成立せず。
- 調整チャートも `奪還・攻撃・移動のいずれも作れない`（`chart_interim_hold`）で
  **数時間にわたり新規ボス波が出ない**。
- 将軍の大半は軌道に野営したまま。野営回収は `wave_active` の延期で動けない。

## 原因

v1284 で `wave_active` の鮮度を6時間へ延ばしたため、ボス波の記録が残っている限り
野営回収が延期され続けた。結果、駐留が空でも回収が走らず、出撃源が無いまま
ボス波だけが古くなっていった。

## 変更

- `boss_pursuit.wave_active`: **城の駐留将軍が合計1名以下**なら False を返し、
  フィールドを野営回収へ渡す。
- 追撃側の停止判定（`wave_stale` / `PURSUIT_STALE_TICKS`）は不変。
- `BOT_VERSION` v1308、hot-load許可リストへ追加。

## 検証

- `tests/test_hanjuku_wave_garrison.py`（2件）: 駐留0/1名→False、2名→True。
- 第9話野営帰還・波・台帳・追撃 43 passed。

## 期待

- 駐留が空のとき野営回収が走り、将軍が城へ戻って新しいボス波が出撃できる。
