# Yジャンプの総量を実行全体で制限する（v426、2026-11-05）

## 症状（実測）

v424 稼働11分で `y_jump_open` が **128件**、v425 でも **27件/1.2分（約22件/分）**。

- 計画が毎観測作り直され（`chart_adjust_applied` も同数）、そのたびに
  `mem['y_jumps']` がリセットされるため、指示ごとのジャンプ上限（6回）が意味を持たなかった。
- 何度試しても Y ビューでカーソルが動かない（`cursor_stationary`）状態が続いている。

## 変更

- `_start_y_jump`: 実行全体で消えない `tally` に `yjump:<step>:<mode>` を計数。
- `_want_y_jump`: その回数が `Y_JUMP_TOTAL_LIMIT`（18）に達したら、以降は Yジャンプを
  始めずに歩く。指示ごと・画面モードごとに独立。
