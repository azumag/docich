# 半熟英雄 第9話: 前線城への直送補給（v844、2026-11-14）

## 症状（#3952 実測 2026-11-11 22:2x–23:0x、v677–v679）

第9話で占領城が 3↔5 を往復し、前線が伸びない。オオキクの守将が交戦ごとに
残HP 18→34→44 と回復し、1人ずつ時間をあけて突っ込む波状攻撃では削り切れない。
前線へは約5分に1人しか届かず、その後方のオシロガ／ドンドンは空になり奪還される。

## 原因（切り分け済み）

- 補給は一城ずつ中継（`hop = route[1]`）。各ホップで「行軍数分 → 到着確認 →
  出撃手続き1回」がかかり、出撃手続きは全体で1本の active スロットを共有する。
- 同時攻撃の機構（`SQUAD=6`）と敗北後の再攻撃は成立しているが、前線城に将軍が
  常時1人しかいないため連鎖しない（補給律速）。

## 変更

- `routes.move_leg` を新設。第9話の move に限り、**中間城がすべて自軍**の道路
  経路なら複数ホップの直送を合法脚として認める。敵城が間にあれば従来の1ホップ。
- `corridor.orders` の move 行先を `route[1]` から `route[-2]`（前線城）へ。
  直送が証明できない場合と、主人公の配置（`_hero_post_order`）は従来どおり。
- `order_allowed` / `_moves_into` を `move_leg` 経由に統一。攻撃は隣接城のみの
  まま（`allowed`）、`guard_free(9)`・6人はMAX・待たない規則も不変。
- `march_arrival_limit`: 直送の行軍を道路ホップ数で下限補正し、途中で overdue
  扱いにならないようにする。

## 未実測・残リスク

- 直送の目的地（複数ホップ先の自城）をゲームが受理することは実機で未確認。
  v677–v679 の実測は「1ホップ中継が律速」までで、直送の成立そのものは次の
  コーナー稼働時の `order_launched` / 到着一覧で確認する。
- 失敗した場合に自動で1ホップへ戻す仕組みは未実装。`sortie_launch_failed` が
  続く場合は本変更を切り戻す判断材料にする（PR本文にも記載）。
