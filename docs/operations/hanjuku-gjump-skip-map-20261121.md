# 半熟英雄: 不在将軍のスキップを将軍ごとに保持する（v1292、2026-11-21）

## 症状（本番 g1288 05:21〜05:29）

v1291 の不在スキップ後も `general_jump_failed` が続いた。
対象は **トレビスとタルタルが交互**（各 `target_seen=false`, `scrolls=40`）。

## 原因

`general_jump_skip` が**将軍1件分のスロット**しか持たず、失敗のたびに上書き
されていた。2名の不在将軍が交互に選ばれると、相手のスキップを消してしまい、
無限にリトライしていた。加えて `_end_general_jump` の先頭に旧形式の代入が
残っており、直後の新形式ブロックがそれを旧形式とみなしてリセットしていた。

## 変更

- `general_jump_skip` を **将軍名→{tick, absent} のマップ**へ。
- 旧形式（`{'general':..., 'tick':...}`）が来た場合は読み捨てて新形式へ移行。
- `_end_general_jump` 先頭の旧形式代入を削除。
- 再アーム判定は将軍ごとに `absent` なら 3600 tick、通常 200 tick。
- `BOT_VERSION` v1292、hot-load許可リストへ追加。

## 検証

- `tests/test_hanjuku_general_jump_absent.py` を2件に拡張（不在1名／2名が互いを消さない）。
- 第9話野営帰還・台帳・マップ 40 passed。
