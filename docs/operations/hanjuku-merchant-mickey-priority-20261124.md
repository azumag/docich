# 行商人の購入順でミックミーを優先する（v1458、2026-11-24）

## 症状

g1342 第4話。月次の行商人で **クースカンばかり**購入し、ミックミーが
ほとんど買われなかった（6-7: クースカン3枚、6-8: クースカン3枚→5枚、
ミックミー0枚）。

## 原因

`BARGAIN_TARGETS` は辞書の並び順（ノリウツール→クースカン→ゼンマイン→
ミックミー…）で購入していた。月次の 200G/8枚の上限では、安い
クースカン（24G）とゼンマイン（32G）を先に目標まで埋めると、
ミックミー（40G）に予算が残らなかった。推奨組は
`クースカン+ミックミーx2`（ID合計47、`replan._strong_stock_kit`）で、
ミックミーは携行枠の要になる。

## 修正（v1458 `hanjuku-chart-v1458-merchant-mickey-priority`）

- 非リッチ商人の購入順を `BARGAIN_ORDER` として明示し、**ミックミーを先頭**に
  する（次に推奨組のクースカン、続いてノリウツール・ゼンマイン・マグネガキン・
  エンジェリン・ころぼぐんだん）。
- 目標在庫・価格上限・予算・所持上限（99枚）の規則は変えない。
- リッチ商人（1000G+）の価格降順ソートは従来どおり。

## 検証

- `tests/test_hanjuku_merchant_bargains.py`:
  - 200Gの実売価格で ミックミー2枚 → クースカン1枚の順に買う。
  - `BARGAIN_ORDER` が全 `BARGAIN_TARGETS` を網羅する。
  - 既存の「実在庫の一覧が暫定候補を置き換える」テストの先頭札を新順へ更新。
- 関連する商人・ショップ・経済・札テスト 289 passed。
- 実機はデプロイ後の月次商人で、ミックミーの購入とクースカン偏重の解消を
  確認する（本ドキュメント時点では未デプロイ）。

## 追補（2026-11-25、v1518）

`BARGAIN_ORDER` はオーナー指示の `CARD_PURCHASE_PRIORITY` から作るようになり、
先頭は エンジェリン→マグネガキン→ミックミー になった（この文書の「ミックミー先頭」は
v1458 時点の記録）。リッチ商人の価格降順ソートも優先度順に置き換えた。詳細は
`docs/operations/hanjuku-card-purchase-priority-20261125.md`。
