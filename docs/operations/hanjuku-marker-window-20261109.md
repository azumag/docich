# 半熟英雄: 選択三角の探索範囲を名簿の実位置まで広げる（v599、2026-11-10）

## 症状（実測）

月次の `post_month_roster_marker_unverified` が **25件中20件**（23:35〜23:37）。
三角マーカーが読めず、将軍ごとにステータスパネルを開いていました。

## 原因

`selection_marker` の探索範囲は **x 16..154 / y 16..178**（256x224 前提）でしたが、
名簿の名前列は **x=168 から**始まり（`house._names_at`）、ライブのフレームは
**299x224**。選択三角は名前の左隣に描かれるため、**x が 154 を超える位置**にあると
探索窓の外になり、検出できませんでした。

## 修正（v599 `hanjuku-chart-v599-marker-window`）

探索範囲を **x 8..200 / y 8..216** に広げました（厳密な7x7パターン照合は不変なので
誤検出は増えません）。スキャン時間は 54ms → 73ms（299x224）。

## 確認

- `tests/test_hanjuku_marker_hint.py` に1件追加: x=162 に置いた三角を検出できる
  （旧範囲では不可）。
- 月次・マーカー・到着系 152件 passed。
- 本番反映後: `post_month_roster_marker_mapped` が増え、未確認（＝ステータスパネル訪問）が
  減ることを実測する。
