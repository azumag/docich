## 修正（v604 `hanjuku-chart-v604-unreadable-name-slip`）

`_selected_actor_guard` の判定順を整理しました。

1. 行・名前が読めない → 3回保留のうえ取り消し（従来どおり）
2. 名前が**予定と完全一致** → 承認（ラベルの列ずれは問わない）
3. 名前が**読み違い**（`_actor_name_slip`: 同字数・非実在名・読めた文字3以上・不一致1以内）
   → **本人として承認**（`sortie_actor_ocr_slip`）
4. それ以外（読めているが別人） → **即取り消し**（主人公を代役にすり替えない）
