# 半熟英雄の右寄せ投影と左余白ステータス

半熟英雄だけ配信側のcontain投影を右寄せし、測定した左余白へ拡張ステータスを表示する。元のRetroArch窓・内部解像度・AI観測・入力座標は変更しない。配信枠は `(0,90,960,540)`、映像の比率と表示寸法、上下・右の共通枠を維持する。他ゲームの中央配置は変更しない。

## 寸法と合成

`presentation.py --align right` は取得したnative窓寸法を、実際のBGRA→FFmpeg scaleで一度測定する。高さ540へのcontain後の幅を固定値で推測しない。例えば299×224の検証用入力は721×540なので、映像は `x=239..959`、左余白は239pxになる。これは合成入力の測定であり、VMの実測寸法ではない。

既存のscaleとpadで全映像を含め、右寄せ時は左側にできた黒余白だけをcropしてffplayの投影窓を映像幅に合わせ、窓自体を測定したcontent xへ移す。元ゲーム窓を縮小・移動する処理ではなく、AI観測と入力座標も元ゲーム側の座標系を使い続ける。ゲーム背面の共通ブラウザー `broadcastGameGap` 面が `x=0` から左余白だけを描画する。

`presentation.json` はready/right/viewport/contentを記録する。299×224の例なら `content=[239,0,721,540]` となる。Sorenはcanonical active runtimeの識別子・世代・leaseとこの幾何を照合し、`side=left x=0 w=239` として公開する。寸法不正、幅180px未満、投影失敗、terminal、観測30秒超、別ゲームへの切替ではカードを出さない。移行中の旧left投影もSoren側では読み取り互換を残すが、新しい半熟起動はrightを使用する。

## 表示する事実

Soren #600で、既存の交戦HP・駐留・行軍・累計占領に加えて左余白へ次を表示する。

- 現在状況: 画面状態、話数、ゲーム内年月、所持金、観測済み兵力。
- 戦績・戦闘: 勝敗、戦闘開始/終了、切り札確定、城失陥。
- 出撃・計画: 成立/失敗、現在の計画、保留計画。
- 卵残回数、失った城、実入力回数・観測回数・最新観測経過秒。
- 占領した拠点は累計記録であり、現在の保有城数として推測しない。
- 駐留は実観測から30秒以内、交戦HPは一致する両軍の実観測から10秒以内だけ表示する。
- 行軍は既存policyのbusy期間内だけを表示し、成立未確認を含むことを明示する。
- 18px本文とカード単位を維持し、実DOMの高さでページ分割して10秒周期で巡回する。

値が未読なら0で補完せず非表示または未確認とする。古い・将来・不正な観測を現在値として表示しない。

## 配備と確認

Soren #600のmainを親のgitlinkへ取り込み、親PR/CI/mainからcanonical VM gatewayで配布する。共有表示serviceのコードが変わるため `shared_overlay_reload_epoch` を更新し、固定helperで表示serviceだけを再読込する。4面のreadinessとencoder/audio/active gameのidentity・PID・起動時刻を前後照合し、継続不一致を成功扱いしない。encoder・共通音声・ゲームは再起動しない。

投影プロセスは起動時に配置を読む。進行中の半熟試合を強制終了せず、その試合が自然に終了して次に半熟が起動する境界で右寄せ配置を有効にする。確認目的の自動切替や試合起動は行わない。

完了には合成ピクセルとChromium描画に加えて、自然登場した半熟の実配信フレームで、左余白カード、右寄せ映像、四辺/スコア/案内の欠けなし、ゲーム画素との非重複、観測値一致、切替後撤去、encoder/audio PID・起動時刻維持、対象mainとVM現物の照合を確認する。配布のみ、fixtureのみでは実配信完了としない。

## Runtime checklist

既存presentation状態とbot stateを使い、worker/queue/model/providerは追加しない。共有overlayの固定route・readiness契約を維持し、秘密情報・本文ログ・任意execの公開は増やさない。投影、state fencing、期限、共有面、切替の回帰テストを実行する。
