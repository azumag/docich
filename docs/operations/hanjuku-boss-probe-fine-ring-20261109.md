# 半熟英雄: 推定ボスセルの探索を2タイルの細かい輪から始める（v544、2026-11-09）

## 背景

第6・7・8・10・11・12話のボスセルは地図データからの**推定**で、v531 の探索候補
（`BOSS_CELL_PROBES`）を1回の未入城ごとに回して当たりを探しています。

旧候補は `(0,0), (0,±64), (±64,0)` の**8タイル単位**でした。推定誤差が1〜2タイルの
場合、隣のタイルには決して当たらず、5候補すべてが外れて章が終われなくなります。

## 修正（v544 `hanjuku-chart-v544-boss-probe-fine-ring`）

候補を「細かい輪 → 粗い輪」の9点に変更しました。

```
(0,0)          … 推定値そのもの
(±16,0),(0,±16) … 2タイルの輪（推定誤差1〜2タイルを拾う）
(±64,0),(0,±64) … 8タイルの輪（従来の広域）
```

- ローテーションの先頭は従来どおり推定値（index 0）。
- 未入城の再出撃ごとに次の候補へ進む挙動（`_relaunch_overdue_boss`）は不変。
- 第5話（WRAM実測）・第9話（移動ボス）は従来どおり探索しない。

## 確認

- `tests/test_hanjuku_boss_cell_probe.py`: 既存21件を新しい候補順に更新し、
  「最初の輪が2タイルを覆う」ことを1件追加。
- ボスセル・移動ボス・章データ 70件 passed。
- 本番反映後: 第6話以降のボスで `boss_cell_probe_shift` が細かい輪の順に出ることを
  実測する（推定が当たれば index 0 のまま）。
