# 第6話ボスセルの実測確認と、未入城の切り分け記録（v402、2026-11-05）

## 目的

第6話のボス（完熟秘密基地）へ5隊出撃したが入城が実測できていない。
原因が「セル誤り」か「出撃が実際には出ていない」かを切り分ける。

## 実測1: ボスセルは正しい

通常11城制圧後の Y ビュー（256x224）を取得して確認した。

- 暗い森のリングと、その中央の基地らしい建物が **px (166.7, 67.5)** にある。
- チャートのボスセル (818, 184) は `WORLD_MAP_OFFSET[6] = (64.3, 45.0)` で
  **px (166.55, 68.0)** に写る。差は 1px 未満。
- 実際の Y ジャンプも目標セルで確定しており、カーソルは (165.5, 70.5) / (165.5, 71.5)。

つまり v395 で入れたボスセル (818, 184) は正しい。セル修正は不要。

## 実測2: 出撃が地図に出ていない

- ボス向けの出撃記録は5件（ヘルメス、リースリング、トレビス、マンゴスチン、フェットチーネ）。
- しかし同じ時間帯の Y ビューの部隊マーカー（▲）は **1個だけ**で、位置は px (107,136)〜(113,141)。
  これはボス方面（166,68）でも出撃元（アルマムーン 113,63 / オケアナ 177,91）でもない。
- つまり「出撃済み」として記録されたボス隊の多くは、実際には地図上を進んでいない可能性が高い。

## 変更

- `boss_sortie_overdue` / `boss_relaunch_exhausted` の記録に、切り分け用の2項目を追加:
  `cell`（その時点のチャートのボスセル）と `source_still_has_general`
  （出撃元の実測名簿に将軍がまだ居るか）。
- 次に未入城が起きたとき、`cell` が正しいままなら原因は出撃側、
  `source_still_has_general: true` なら「出ていない」と確定できる。
- 判定・出撃・待ち時間の挙動は変えない（記録のみ）。
