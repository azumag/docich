# ボス目標をマーカー位置でも確定できるようにする（v410、2026-11-05）

## 症状（実測）

第6話ボスへの出撃で、全体マップ（Y）のジャンプが繰り返し失敗していた。

- `y_jump_open` → `y_jump_failed`（`moves: 3, stationary_reads: 3`）。
- ボス目標は「Yジャンプで確定したときだけ」受理する規則のため、
  ジャンプが失敗するとボス城へ出撃できない。計画は同じボス隊を出し直し続けた。

## 変更

- `_target_roof_under_marker`: ボス目標は、Yジャンプの確定に加えて
  **マーカーが実測セルの上に立っていれば**確定として扱う（許容 3タイル = 24）。
- セル自体は v402 で撮影フレームと突き合わせて検証済み（誤差1px未満）。
- 通常の城は従来どおり屋根（own/enemy）でのみ確定する。

## 検証

- `tests/test_hanjuku_boss_marker_confirm.py`（新規4件）:
  セル上のマーカーで確定／離れたマーカーは不可／Yジャンプ確定は従来どおり有効／
  通常の城は屋根が必要なまま。
- 修正前は1件失敗、修正後 4 passed。関連（`boss_sortie_overdue` / `boss_wave_solo` /
  層 / `chart_bot`）を含め 367 passed。
