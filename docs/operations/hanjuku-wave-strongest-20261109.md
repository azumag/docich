# 半熟英雄: 波状攻撃は「強い将軍」から送る（v627、2026-11-10）

## 症状（実測 09:38）

しまばら攻撃で `sortie_outcome` **won**（味方18 / 敵0）の直後に
`attack_defender_successor`（味方18 / **敵85**）＝**2人目の守備将軍**が出て攻撃が終了。
同じ城を何度も攻めても、弱い将軍から送っていたため落とせませんでした。

## 原因

`_wave_pick` は城の名簿順の**先頭の余剰**を選んでいました（`spares[0]`）。
名簿は強さ順ではなく、実際に弱い将軍から出ていました。

## 修正（v627 `hanjuku-chart-v627-wave-strongest`）

波状攻撃の将軍選びに既存の `_strongest_first`（実測HPの降順、HP0は修理へ）を使います。
「城を空にしない」「予約済み将軍は使わない」規則は従来どおりです。

## 確認

- `tests/test_hanjuku_boss_wave_solo.py` に1件追加（弱い将軍ではなく強い将軍を選ぶ）。
- 波状・計画・出撃優先度・診断 119件 passed。
- 本番反映後: しまばらの2人目守備将軍に勝ち、`castle_owned_observed` が増えることを実測する。
