# 半熟英雄: 行軍の到着上限を全章で実測レートにする（v597、2026-11-09）

## 症状（実測）

g1163 第8話 2026-11-09 23:22:34、**あるまむーん発の3件**が同時に `sortie_march_overdue`。

| 将軍 | 行先 | 経過 |
|---|---|---|
| ブラマンジェ | おかざき | 1813 |
| ビシソワーズ | おだわら | 1675 |
| ラズベリー | まつやま | 1705 |

おだわら (856,656)・まつやま (504,128) は あるまむーん (136,912) から遠く、
**まだ歩行中**の可能性が高いのに「上限超過」で出し直しになっていました。

## 原因

`march_arrival_limit` は `MARCH_TICKS_PER_CELL`（**第6話のみ 3.2**）を引き、
未登録の章は **固定 `BOSS_ARRIVAL_LIMIT`（800）** に落ちていました。
行軍速度はゲームの歩行速度であり章の性質ではないため、他章でも同じレートで見積もるべきです。

## 修正（v597 `hanjuku-chart-v597-march-rate-default`）

`DEFAULT_MARCH_TICKS_PER_CELL = 3.2`（第6話の実測値）を追加し、
章別の登録が無い場合はこれを使います（章別の上書きは可能なまま）。

- あるまむーん→おだわら: 800 → **2400**（`MARCH_ARRIVAL_CAP`）
- あるまむーん→おかざき: 800 → **1195**（距離比例）
- ボス行軍は従来どおり `MARCH_ARRIVAL_CAP`。
- **第3話・第4話は従来の固定上限のまま**（道路マップの実測が無く、再送予算が
  800上限に合わせて校正されているため。`FIXED_LIMIT_CHAPTERS`）。

## 確認

- `tests/test_hanjuku_march_rate_default.py`（新規4件）: 章別未登録でも実測レート／距離比例／
  第6話の値は不変。
- 行軍・計画・出撃 468件 passed。
- 本番反映後: 長距離行軍の `sortie_march_overdue` が減り、入城（`attack_observed`）が
  増えることを実測する。
