# 半熟英雄: 空の城には「その周回で最も優先度の低い攻撃」を回す（v593、2026-11-09）

## 症状（実測）

g1163 第8話 2026-11-09、**しらかわ の駐留が空**（`garrison: []`）のまま放置され、
その前に ながはま も守備1人（アテナ）でキッシュに落とされていました。

## 原因

`interim_candidates` は攻撃候補を作る段階で**全ての余剰将軍を予約**します。
その後に走る `_garrison_rotation`（増援の移動）には回せる将軍が残らず、
**空の城へ誰も送られない**ままでした。

## 修正（v593 `hanjuku-chart-v593-empty-castle-staffing`）

攻撃と回転の予約が終わった後に、**空の城（記録上0人）**があれば:

- その周回の**最も優先度の低い攻撃候補（末尾）を取り下げ**、その将軍を空城への移動に回します
  （将軍の二重使用はなし。奪還の予約将軍は奪わない: 2026-11-05 #3266）。
- 移動は候補の先頭側（ボス波より前）に置きます。
- **ボスだけが残った局面では行いません**（2026-11-05 オーナー: 空城への移動は廃止）。
- 空城が複数あるときは、攻撃候補がある限り1つずつ充当します。

## 確認

- `tests/test_hanjuku_empty_castle_staffing.py`（新規2件）: 空城に移動が入り攻撃より前に来る／
  全通常城取得済み（ボスだけ）では移動しない。
- 計画・チャート・ボス・増援 437件 passed。
- 本番反映後: 空の城が減り、`castle_lost_observed`（守備0/1人）が減ることを実測する。
