# 半熟英雄: 月初に兵士数・将軍数を先に確認する（v503、2026-11-07）

## 指示と変更

オーナー指示: 月次コマンドが始まったら、募集などの前に兵士数と将軍数を
確認する。前月人数や一部の将軍だけで募集人数を決める差異を防ぐ。

既存の国ステータス訪問を月初へ優先する。情報画面の1頁目で兵士数と将軍数を
同じラン・章・月に紐づけて読むまでは、未開始の募集計画や卵回復予定、
当月の部分名簿がこの訪問を後回しにしない。両方の当月観測があれば、募集の
たびの再訪問はしない。レベル確認の既存経路と、確認後の購入優先順位は維持する。

すでに支払い確認中の補充や募集会話は完了させる。未払いの旧人数前提の
まとめ募集は、国ステータスで新人数を読んだら予算・人数を作り直す。
支払い済みの募集会話と進行中の有料バッチのreceiptは作り直さない。

`country_count` はidentity・章・月・観測tick・範囲を検証し、boolや未来の観測は
人数として使わない。月初の国ステータス訪問を開始した後に将軍数が未読なら、
前月人数・部分名簿・駐留一覧へ戻って募集を許可しない。次の募集の現金確認も
この条件を照合する。確認は既存の月2訪問と各段階の有限予算を使い、
読み取れないまま無限に月を保留しない。兵士数未読時の既存の無料補充確認も残す。

## 検証

合成画面を本物のparser・orchestratorへ通し、次を確認する。

- 卵回復予定・名簿receipt・未払いのまとめ募集・募集完了後のいずれでも、
  月初の人数未確認なら先に国ステータスへ向かう。
- 前月4人から現在6人・兵士0人を読み、支出計画前に現在値へ更新する。
- 4人前提の未払いバッチを破棄し、新人数と今回読んだ収入・賃金で組み直す。
- 未読のまま訪問予算を使い切っても、過去人数・部分名簿で募集しない。
- 支払い中の会話・receiptと、確認済み月のまとめ募集を中断・再走査しない。
- 不正scope・別identity・未来tick・boolを人数扱いしない。
