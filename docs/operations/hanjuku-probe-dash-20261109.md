# 半熟英雄: 出撃計画のプローブ俳優を「—」にする（v595、2026-11-09 オーナー指摘）

## 指摘（オーナー）

「というか存在しない将軍が出撃計画に入っている？」

v586 で `しょうぐん` → **余剰将軍** に変えましたが、**名前のような文字列**であるため
配信の出撃計画に「存在しない将軍」として表示されていました。

## 原因

`source_probe`（一覧から将軍を選ぶ偵察出撃）は、内部の俳優トークンを `general` 欄に
入れています。この欄は配信で**将軍名としてそのまま表示**されます。

## 修正（v595 `hanjuku-chart-v595-probe-dash`）

- `PROBE_GENERAL = '—'`（全角ダッシュ）に変更。将軍名と誤読できない表記にします。
- 入力側は後方互換: `しょうぐん` / `余剰将軍` / 空文字 も probe 俳優として受理。

## 確認

- `tests/test_hanjuku_off_chart.py` を新表記へ更新（旧表記も受理されることを確認）。
- 計画・チャート・ボス・増援 427件 passed。
- 本番反映後: 出撃計画の `general` が **—** になり、存在しない将軍名が出ないことを実測する。
