# 半熟英雄: 2人待ちの間に実行中の攻撃を止める（v778、2026-11-13）

## 症状（実測 g1163 2026-11-13 18:33）

前線 `ドンドン` が1人になり、2人待ち（`front_wait_mass`、need 3）が
再び有効になったあとも、実行待ちだった攻撃指示が進み、
`マフィン`・`シェーブル` が単独で `オオキク`（守備将軍65HP）へ出撃して
失われました。

```
18:32:16 front_wait_mass  {"need": 3, "residents": ["カシュー","レモン"]}
18:33:06 front_wait_mass  {"need": 3, "residents": ["レモン"]}
18:35:15 order_launched   I:c9:ドンドン>オオキク:92 マフィン
18:36:41 order_launched   I:c9:ドンドン>オオキク:93 シェーブル
```

## 原因

corridor は `front_wait_mass` のとき**新しい**攻撃指示を出しませんが、
すでにプランで `active` になっている攻撃ステップは実行が続きます。
前線の人数が減って待ちが再武装しても、その1件は止まりませんでした。

## 修正（v778 `hanjuku-chart-v778-mass-retract-active`）

`front_wait_mass` の分岐で、`plan['active']` が同じ出撃元・対象の
攻撃ステップ（`I:c9:出撃元>対象:番号`）なら:

- `plan['active'] = None` にして実行を止める。
- そのステップの状態を `pending` に戻し、後で再計画できるようにする。
- `front_mass_retracted` を記録する。

これにより、待ちの間は増援の移動指示が選ばれ、城を埋めてから
2人同時の攻撃に移れます。

- 代わりに `オシロガ>ドンドン` などの増援移動が選ばれること。
- 前線が3人になってから2人同時の攻撃が出ること。
