# 新しい在城観測と古い行軍記録の矛盾

卵修理は行軍中の部隊へ目的地を再指定しない。しかし旧 `en_route` /
`launched_unconfirmed` だけを無期限に優先すると、到着通知を取り逃した将軍を
現在の本人ステータスで「しろのなかにいます」と読み直しても修理候補から除外し続ける。

正常な本人ステータスから在城を読み取っても、古い出撃記録の存在だけでcloseへ進む経路を
変更前の実関数と合成native文字画像で再現した。資金、他の守備将軍、
移動中の安全など別の制約は残るため、この変更だけで修理や勝利を保証しない。

## 変更の限界

- 本人の正常なステータス読取へ観測tick・章・月を付ける
- 同章・同月、現在から400観測以内、出撃記録より後の在城観測だけで、
  城内の一覧を再確認する経路へ進める
- 新しい出撃、古い/未来/欠損/不正な観測、移動中、不明状態は従来どおり保留
- 出撃記録を「到着」に書き換えず、到着城も推測しない
- 実在城一覧、対象本人、残す守備、HP、修理費、贈り物購入・修理完了条件は維持

変更前の実関数で新在城status→旧行軍記録→closeを再現し、変更後はfind_castleへ。
合成native文字画像の正常・否定例で検証する。次の自然なランでの修理成功は未検証。
