# 半熟英雄: 月一の国ステータスを1回で読み、将軍数・兵士数を更新する（v511、2026-11-07）

## 症状

オーナー報告（2026-11-07）:

- 月一コマンドでは最初にステータスを開き、兵力・将軍数・現在収入・総賃金を更新する
  はずだが、将軍数と兵士数が更新されない（配信カードの兵力・将軍数が古いまま）。
- 月一コマンド中にステータスを2回開いていて冗長。

## 実測（本番 g1153、JST）

### 1頁目の実文言（22:57:08 の実フレーム）

```
2わ3ねん1のつき57G
しゅうにゅう 30G
そうちんぎん 21G
しょうぐん 12にん
しろ 1コ
きりふだ 39コ
へいし 89にん
```

- 人数行は **「しょうぐん Nにん」「へいし Nにん」**。v503/v509 が探していた
  `しょうぐんにんすう` などの長いラベルは実画面に存在せず、`country_general_count` /
  `country_soldier_count` は null のままだった（`hanjuku_bot.json` で確認）。
- 収入・賃金だけは同じ頁で読めていたため、カードの現在収入・総賃金だけが更新されていた。
- 1頁目は `main_menu` に分類される（メニュー上に情報頁が重なる）。2頁目は
  `たまご8コ / はんじゅくレベル3 / はんじゅくち293 / つぎのレベル400`。

### 2回開いていた実測（22:56:20 と 22:56:32）

章が変わった直後の月（2わ3ねん1のつき）で、`house_scan_started` が12秒間に2回。

1. 22:56:20 月一の国ステータス確認を開始（メインメニューを開く）。
2. 22:56:26 開いたメニューのヘッダから章2を観測 → `chapter_seen`。
   `_enter_chapter` が `house`・`month` を破棄したため、開いているメインメニューが
   無主になり `close_panel` が B を送って月一メニューへ戻した。
3. 22:56:32 月を再検出して同じ確認をやり直し、2回目のメニューでステータスを開いた。

同じ月に2回走る現象は 2026-11-05 の既知残件（月次名簿スキャン時代から）で、
複数世代のログに 30〜120 秒間隔の対が出ていた。人数が未読のままの月は
「人数未読 → 同じ月にもう一度確認」の再試行でも2回になっていた。

## 変更

- `flows/house.py`
  - 1頁目（`しゅうにゅう`/`そうちんぎん` がある頁）を人数の唯一の情報源とし、
    `_country_status_counts` で長いラベル → `しょうぐん`/`へいし`（直後が
    `めい`/`にん`/`人` のときだけ）の順に読む。商人価格やメニュー行の数字を
    人数にしない。
  - 1頁目を読めたのに人数行を特定できないときは `house_country_status_counts_unread`
    を1訪問1回だけ記録し、頁の行文言を残す（次回の語彙確認用）。
  - 収入・賃金・半熟レベルの既存の扱いは変えない（読めた頁だけが上書き）。
- `strategy/campaign.py`
  - 章の切替時に、進行中の月次国ステータス訪問（`house.level_only` かつ
    month_open/open_roster/level_status/leave_status/leave_roster）は破棄せず、
    `chapter` だけ新しい章へ更新して続行する。新しい章の月の情報を、開き直さずに
    同じ訪問で読む。フィールド調査（`month_scan=False`）は従来どおり破棄する。
- `flows/month.py`
  - 将軍募集が未決（`pending`/`check`/`deferred_egg`）の間は、商人の切り札と
    築城の購入をその月見送る（`month_cards_held_for_recruit`、`cards_held`、
    `chikujou=skipped`）。卵回復と兵士補充は従来どおり先に進める。
    人数が未確認（`deferred_roster`）の月は従来の購入順位を保つ（切り札購入を
    止めるのではなく、次月の国ステータスで人数を読む）。
- `BOT_VERSION` を `hanjuku-chart-v511-month-status-single-read-and-counts` へ更新し、
  diagnostics の許可集合へ追加。

## 追補（v512、2026-11-07）

城ステータス頁も `しゅうにゅう` と `しょうぐん Nめい` を持つため、収入行だけを
国の1頁目の根拠にすると、誤って城ステータスを読んだときに将軍数0を書き込み、
国の収入を城の収入で上書きしうる。1頁目の判定を **`そうちんぎん` がある頁**に絞り、
収入・賃金・人数・半熟レベルの読み取りを同じ頁に限定した（v512）。
城ステータス頁では人数・収入・賃金を書かない回帰テストを追加。
