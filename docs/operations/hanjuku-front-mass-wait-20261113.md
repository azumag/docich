# 半熟英雄: 退けられた前線で1人ずつ突っ込み続けるのをやめ、2人同時出撃まで集める（v757、2026-11-13）

## 症状（実測 g1163 2026-11-13 09:3x〜10:5x）

第9話の前線 `オオキク` から `ナッテ` への攻撃が、**毎回1人だけ**で行われ、
元気な守備将軍に退けられていました。

| 時刻 | 結果 | ally HP | enemy HP |
|---|---|---|---|
| 09:30:51 | won | 93 | 0 |
| 09:32:44 | lost | 0 | 46 |
| 09:42:52 | lost | 0 | 32 |
| 10:57:40 | lost | 0 | 39 |

`front_guard_held` は `オオキク` の在城者1人で攻撃を止めます。在城者が2人に
なると1人を残して1人だけ出撃するため、**同時に2人がナッテへ向かうことが
ありません**。守備将軍は攻撃の間にHPを戻し、次の1人も各個撃破されます。

`_repelled_alone()`（最後の攻撃が `lost` かつ enemy_hp >= 30）は既にありましたが、
計画から使われていませんでした。

## 修正（v757 `hanjuku-chart-v757-front-mass-wait`）

第9話の攻撃で、対象の最後の攻撃が元気な守備将軍に退けられている間は、
前線の在城者が `_keep + 2` 人（通常3人、取ったばかりで揺れる城は4人）に
なるまで攻撃を保留します。

- 2人が余れば、連続する観測で2人を出撃させ、同じ守備将軍に同時に当てられる。
- 6人を待つ意味ではない（オーナー 2026-11-11「6人はMAX」）。待つのは
  「2人同時」の最小限。
- 守備将軍が瀕死（`_defender_nearly_dead`）なら待たずに止めを刺す。
- 自城の奪還（`purpose == 'retake'`）は待たない。
- `FRONT_MASS_WAIT=900` tick で上限。補給が来ない前線は従来どおり攻撃する。
- 前線が `_keep + 2` 人に達したら保留タイマーを消す。

## 検証

  - 守備将軍が瀕死なら2人でも止めを刺す

  - 最後の攻撃が勝ちなら待たない

## 本番反映後に実測すること

- `front_wait_mass` が記録され、`オオキク` の在城者が3人になるまで攻撃が
  保留されること。
- 3人になった後、`ナッテ` へ2人以上が同時に行軍し、戦闘で守備将軍を
  削り切れること（`sortie_history` の `enemy_hp` と勝敗）。
- 第9話の road が `ナッテ`→`シマウ`→`カラ`→`イソ`→`イデ！` と進むこと。

## 残件

- 第9話の進行と12話ボス撃破は引き続き実測で確認する。
- 補給路（オシロガ→ドンドン→オオキク）が細い場合、3人揃うまで時間がかかる。
  900 tick で単独攻撃に戻るため、停滞が続く場合は補給側を別途直す。
