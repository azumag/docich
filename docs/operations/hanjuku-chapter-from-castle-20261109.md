# 半熟英雄: 章が未測定でも一意な城名から章を確定する（v641、2026-11-10）

## 症状（実測 21:1x）

状態を初期化してゲームを再開したところ、`chapter: None` のまま**月次の買い物だけ**を
繰り返し、攻略が始まりませんでした（`variant: chart_unavailable`）。

## 原因

章の確定は「再開フラグ（`resume_chapter_pending`）＋一意な城名」の組み合わせだけで行われて
いました。状態を初期化したランではこのフラグが無いため、**一意な城名を見ても章を確定できない**
状態でした。

## 修正（v641 `hanjuku-chart-v641-chapter-from-castle`）

**一意な城名**（その城名が1つの章にしか存在しない）を確認したら、再開フラグが無くても
その章で確定します（`len(matches) == 1` の条件は不変）。

## 確認

- 章・チャート・出撃・診断 **533件 passed**。
- 本番反映後: `chapter` が確定し、月次だけでなく攻略（出撃）が始まることを実測する。
