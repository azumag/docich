# 半熟英雄: 短い将軍名の読み落としも本人として扱う（v606、2026-11-10 オーナー報告）

## 指摘（オーナー）

「こんどはキールの出撃がキャンセルされているね」

## 実測

`sortie_actor_unconfirmed` の `observed` は **「キ??」（`?` は読めない文字）**、
`selected` は **キール**。v603/v604 の読み違い救済は「読めた文字が3文字以上」を
条件にしていたため、**3文字の名前で2文字読めない**この場合は救済されず、
3回保留のうえ取り消し→再試行を繰り返していました。

## 修正（v606 `hanjuku-chart-v606-short-name-slip`）

`_actor_name_slip` の条件を緩和しました。

- 従来: 読めた文字が3以上かつ不一致1以内
- 追加: **読めた文字が1以上・不一致0・名前が3文字以上** でも読み違いとして採用
  （読めた文字がすべて同じ位置で一致しているため）

実在の別将軍（例: `ゼウス` vs `キール`）は従来どおり拒否します。

## 確認

- `tests/test_hanjuku_sortie_evidence.py` に1件追加（`キ??`→キールは本人、`ヒ??`・`ゼウス`は別人）。
- 出撃・証跡・診断 222件 passed。
- 本番反映後: キールの出撃が通り、同じ出撃の繰り返しが消えることを実測する。
