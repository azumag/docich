# 通常城への出撃確定（v246）

2026-10-21の「城のないような変なところに出撃しようとしている」という報告を受け、通常城の最終決定で現在の画像・マーカー・期待する所有者の屋根が必要になるようにする。

以前は画像またはマーカー欠落を許可し、屋根が0件の場合も以前のY全体マップ移動記録だけで出撃確定を許可していた。この二つを拒否する。Y移動はナビゲーションのヒントとして保持するが、通常城の決定証拠にはしない。現在の画像で確認できなければ既存の有限再観測・取消経路へ戻す。未確認の出撃をlaunched/en_routeと記録しない。

冬の配色で屋根を読めない場合も保留する。冬の正常な城を認識できることは別の実画像検証が必要で、古い例外を戻して代用しない。屋根のないボス塔は既存の専用Y移動条件を維持するが、画像・マーカー欠落は許可しない。屋根の所有者と位置の一致は城名一致の証明ではなく、正しい城への到着・占領の受入は別に確認する。修理の家への移動と帰還経路は本変更の対象外。

今回の再現は、屋根0件・過去のY移動一致・nav到達判定の合成入力で、修正前は最終guardがtrue、修正後はtarget_stepがAを送らず再観測となること。現行自然runの同一入力・画面はまだ取得しておらず、ユーザー報告の原因を特定済みとはしない。#2545の保留を解除する変更ではない。
