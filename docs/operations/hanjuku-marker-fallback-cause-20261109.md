# 半熟英雄: 三角マーカーが無い場合も理由を残す（v598、2026-11-09）

## 背景（実測）

v596 で結び付かない理由を記録するようにしましたが、実際の内訳は
**25件中20件が理由 None** でした（23:35〜23:37 の月次）。

## 原因

`_marker` は**白い選択三角が見つからない**と、赤い部隊マーカーによる従来経路へ
フォールバックし、その結果には `marker_reason` を付けていませんでした。
実際の大半は「三角マーカーが読めない」ケースです。

## 修正（v598 `hanjuku-chart-v598-marker-fallback-cause`）

フォールバック経路でも理由を残します。

- `no_selection_marker`: 三角も部隊マーカーも無い
- `many_markers`: 部隊マーカーが複数あり1つに絞れない
- `army_marker_fallback`: 赤マーカー1つで城を推定（従来の経路）
- `candidate_boxes`: 見えたマーカーの箱（最大4件、診断用）

## 確認

- `tests/test_hanjuku_marker_hint.py` に1件追加（三角が無いとき `no_selection_marker`）。
- 月次・マーカー・診断 92件 passed。
- 本番反映後: 次の月次で `marker_reason` の内訳を実測し、最多の原因（三角が読めない）に
  対する検出改善を次に入れる。
