# 半熟英雄: 駐留が未読の城にも2人目の守備を送る（v583、2026-11-09）

## 症状（実測）

g1163 第7話 2026-11-09 19:49:19、フィロメラ が陥落。失陥記録は `garrison: []`
（駐留の記録なし）でしたが、戦闘パネルの守備将軍は **ラビオリ** でした。
つまり**守備はいたが、記録が未読だった**城です。

## 原因

`_garrison_rotation`（前線の城へ将軍を回す仕組み）は、
`garrison.get(target) is None`（＝駐留が未読）の城を**対象から除外**していました。
「未読だから分からない」まま放置され、その城が実際に落ちていました。

## 修正（v583 `hanjuku-chart-v583-unread-garrison-reinforce`）

未読（行が無い）の城も回転の対象にします。

- 到着すれば駐留リストも読めるので、次の周回で実態が分かります。
- すでに送った直後の城（`unread_dispatches`）と、同じ計画で対象済みの城は従来どおり除外。
- 送り出し元は従来どおり「2人以上いて、床（floor）を割らない」城だけ。

## 確認

- `tests/test_hanjuku_garrison_rotation_unread.py`（新規）: 駐留行の無い前線の城へ
  移動候補が出る。
- 計画・チャート・ボス波 426件 passed。
- 本番反映後: `garrison_known: false` だった城に増援が入り、同じ城の失陥が減ることを
  実測する。
