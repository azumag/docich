# 半熟英雄: 自城への移動は全体マップ▲を1回で諦め、出撃元一覧で確認する（v768、2026-11-13）

## 症状（実測 g1163 2026-11-13 12:3x〜15:3x）

`オシロガ>ドンドン` など**自城への移動**で、出撃コミット後の全体マップに
部隊▲が現れず、`LAUNCH_PROBE_READS=5` 回の全体マップ確認（約10秒）を
毎回費やしたあと、結局 `sortie_launch_unverified` で出撃元の将軍一覧を
読んでいました。

自城への移動は行先が友好城のため、ゲームが部隊▲を描かないことがあります。
その場合の受領証は出撃元一覧（本人が消えたこと）であり、▲の5回待ちは
無駄でした。

## 修正（v768 `hanjuku-chart-v768-own-target-marker`）

`_probe_launch_markers` で、probe の target が `_owned(mem)` に含まれる
（自城への移動）場合は、▲の確認を **1回**で打ち切り、出撃元一覧の確認
（`_read_source_roster`）へ進みます。

- 敵城への攻撃は従来どおり5回（▲が出る可能性がある）。
- ▲が実際に現れた場合は、1回でも `sortie_launch_confirmed`（近傍マーカー）。
- 自城移動の受領証は従来どおり出撃元一覧。
