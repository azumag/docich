# 半熟英雄: 直近に攻められた前線は増援が無くても最後の1人を出さない（v781、2026-11-13）

## 症状（実測 g1163 2026-11-13 19:3x）

`ドンドン` が敵に攻められた直後（`defense_seen['ドンドン']=141585`）で
在城者は1人でした。他の城に既知の増援がいないため、v735 の1人待ちの上限
（600 tick）が来ると最後の1人を `ナッテ` 方面へ出して城が空になります。

空になった城は敵に取られ、v779 で守った意味がなくなります。

## 原因

v779 の「増援がいる間は最後の1人を出さない」は、**増援が既知の城にいる
場合だけ**守ります。増援が無い（または未発見の野営にいる）場合は v735 の
上限が働き、直近に攻められた城でも最後の1人を出していました。

## 修正（v781 `hanjuku-chart-v781-defended-last-resident`）

1人待ちの解除条件に「**直近に攻められていない**」を追加しました。

- `defense_seen`（せめこまれました）の窓内（900 tick）にある城は、
  増援が無くても最後の1人を出さない。
- 窓を過ぎれば従来どおり v779/v735 の条件で判断する。
- `_finish`（守備将軍がほぼ瀕死）は従来どおり優先。

## 検証

- 新規 `test_a_just_defended_front_keeps_its_last_resident`:
  `defense_seen` があり増援が無くても、上限後は出撃しない。
- corridor / 前線 / capture guard / 派遣 関連 **183件 passed**。
- 修正前の `corridor.py` では新テストが失敗することを確認。

## 本番反映後に実測すること

- `defense_seen` の窓内では1人の前線が `front_guard_held` になり、
  `front_guard_timeout` で単独出撃しないこと。
- 守備将軍が城に残り、敵の再攻撃を防げること。
- 窓を過ぎた後の判断が従来どおりであること。

## 残件

- 攻められ続ける城は1人で籠城し続ける（守備戦で落ちる可能性は残る）。
  増援・帰還で埋める経路は v772〜v780 で改善済み。
- 第9話の進行と12話ボス撃破は引き続き実測で確認する。
