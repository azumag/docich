# 半熟英雄: 主人公は前線のひとつ後ろの自城に常駐する（v684、2026-11-12）

## オーナー指示

> 主人公は前線の自城一つ前の自城に常駐したほうが良い。新しく将軍をやとったときに
> 常に主人公のいる後方から送ることになる。なので、自城を確認し、その一つ手前の自城に
> 送ることを優先するようにして

## 変更

第9話の機械進軍（`strategy/corridor.py`）で、主人公の移動先を「前線の1つ手前の自城」に固定しました。

- `HERO_POST_HOPS = 3`: 目標城から3つ目（＝前線の1つ後ろ）の自城を定位置とする。
- 主人公がそこより後ろにいる → 1ホップずつ前進（従来どおり）。
- 主人公がそこにいる → 移動指示を出さない（常駐）。
- 主人公が前線（目標から2つ目）にいる → **1ホップ後ろへ戻す**。
  前線に残すと、雇った将軍が前線に湧いて後方から送る流れが崩れるため。
- 前線より後ろに自城が無い（本城が前線）場合は動かさない。

## 確認

- `tests/test_hanjuku_hero_post.py`（5ケース）: 前線から戻す／後方から1ホップ前進／
  定位置なら動かさない／本城が前線なら動かさない／行軍中は二重指示を出さない
- 第9話 corridor・機械進軍・層テスト **74 passed**
- 本番反映後: 主人公が前線の1つ後ろに居ることを `garrison` で、雇用した将軍が後方から
  送られることを出撃履歴で実測する
