# 半熟英雄: 第9話では主人公以外は退却しない（v573、2026-11-09 オーナー指示）

## 指示

「９話では、しゅじんこう（どうし）以外は『たいきゃく』を選ばないようにして」

## 対応（v573 `hanjuku-chart-v573-ch9-hero-retreat-only`）

`battle_menus._retreat_forbidden(mem, cur)` を追加し、`_hero_retreat_menu` の先頭で判定します。

- 第9話かつ戦闘の `ally` が主人公（`どうし` / `しゅじんこう` / `しじんこう`）以外なら、
  **たいきゃく を選ばず** `None` を返します。以後は卵・切り札・奥の手の経路で応戦します。
- 記録は `battle_retreat_forbidden`（同一戦闘で1回だけ）。
- 第9話以外、および主人公本人の退却は従来どおり。

退却の選択は `_hero_retreat_menu` に一本化されているため、この1点で
「将軍がたいきゃくを選ぶ」経路を塞げます（防御戦は元々退却不可）。

## 確認

- `tests/test_hanjuku_ch9_retreat.py`（新規4件）: 第9話の将軍は不可／主人公は可／
  他話は不変／記録は1回だけ。
- 退却・卵・奥の手・戦闘メニュー系 256件 passed。
- 本番反映後: 第9話の戦闘で `battle_retreat_forbidden` が出て、将軍が退却せずに
  卵・切り札・奥の手で戦うことを実測する。
