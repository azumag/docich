# v96 募集実残金の再判定と召喚戦の敗因対策

## 自然な募集見送り

g498-073d3f66/gen498/v95、decision1462/1790735246.5381103、月1-6。
在城＋確定行軍の確認下限3人（総在籍数/死亡は未分類）。216G、募集費保留36G、
兵士0。卵予備費150Gを理由にrecruit_skip。その後全回復の実見積もりは50G、
支払確認1790735287.7326217で166G。募集費50G＋賃金30Gが残っていたのに、
募集はskippedのままmonth_done。将軍不足時の資金先取りだけでは解決しない。

v96では募集費＋賃金が実所持金にあり、保留理由が未完了の卵予備費だけなら、
募集をcheckのまま保留。卵回復の完了と実残金を確認して同月募集を再判定する。
募集を開く前に既存の月次サブ処理を完了し、回復支払の追跡を上書きしない。
実残金が足りない場合は見送り、原典札の購入と卵回復・賃金条件は維持する。

## ヴィーナスの召喚戦敗北

同g498、1-V2/カストーラ攻撃対カシュー。step1047/1790734650.2162385は
味方エクスカリバー299対敵将軍39でエクスカリバる。step1086/1790734709.5825396
では味方282対ダークエルフ240でも同じ即死技。step1095/1790734723.1944075は
卵不能の将軍メニューでBを一度試し、次も同じ画面なのにAへ進んだ。
step1200/1790734880.4745817でヴィーナス0対カシュー39のloss。その後ゼウスが
同城を奪った。敗北は確認済み、死亡告知・退却成功は未確認。リング画像は
対応SHAを照合できていないため、敗戦画面の証拠として使わない。

GCGXのSFCデータではエクスカリバるは即死、マサムネるは4回攻撃。
https://gcgx.games/hanjuku/super_egg.html
即死成功率は対エッグモンスター11/使用者現在HP、対ボス1/256。
https://gcgx.games/hanjuku/tips.html
282HPでの即死は約3.9%（攻略データに基づく計算で、この戦闘の乱数は未測定）。

v96は実味方エクスカリバー・両技一致・敵が既知召喚獣の場合だけ4回攻撃を
優先。対将軍の即死、敵側技選択の有限待機、危険HPでの卵帰還は維持する。
同HPの旧キャッシュにも適用する。一般的な全技最適化や勝利保証ではない。

卵/札が無い攻撃戦はBで通常コマンドへの復帰を最大3回確認。同画面のままなら
unavailableを記録し応戦する。Bで実際に戻れることや退却成功は未実証。
通常メニューに到達した場合は、古い満タンHPの記憶でもたいきゃくを選ぶ。
防衛戦の退却禁止は維持する。将軍HP0を死亡数へ自動換算しない。

減っただけなら支払を確定しない。全半熟の最終結果はPR検証欄を参照。
