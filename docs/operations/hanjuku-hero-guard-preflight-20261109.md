# 半熟英雄: 主人公の城が薄いときに出撃を開始しない（v532、2026-11-09）

## 症状

g1163 第5話 04:38:54〜04:39:07 JST。調整チャートの注文
「暫定: しょうぐんでカルーンを攻撃」を開始し、城メニュー → 将軍一覧まで進んだ
ところで `sortie_held_hero_guard`
（主人公の城に主人公以外の将軍を2人残せないため出撃を取り消す）で取り消された。
出撃元アルマムーンは どうし（主人公）+ ピオーネ + ミント の3人で、
1人出すと主人公以外は1人しか残らない。取り消し後は同じ条件の再発行が抑止され、
調整チャートの到着まで待っていた。

## 原因

計画側の `_source_spare_missing` は「出撃元に2人以上いるか」しか見ておらず、
実行側の `chart_adjust.hero_guard_short`（主人公の城は主人公以外を
`HERO_CASTLE_GUARD`=2人残す）と一致していなかった。そのため、実行時に必ず
取り消される出撃を、城メニューを開く前に弾けなかった。

## 修正（v532 `hanjuku-chart-v532-hero-guard-preflight`）

`strategy/orders._source_spare_missing` に実行側と同じ判定を足した。

- 対象は**チャート外の注文**（`I:` / `A:` で始まる step）だけ。基本チャートの
  注文は従来どおり（実行側の `_keep_hero_guard` も同じ範囲）。
- 自城が2つ以上のときだけ（唯一の城では主人公だけになれる既存ルールを維持）。
- 出撃元が主人公の城で、記録済みの在城一覧が `hero_guard_short` に該当する場合は
  その注文を開始しない。別の出撃元・別の注文が選ばれる。

## 確認

- `tests/test_hanjuku_hero_castle_guard.py` に4件追加:
  主人公+2人では開始しない／主人公+3人なら開始する／主人公自身の出撃は対象外／
  別の城の1人残しルールは変わらない。
- 主人公の城・チャート外・計画・出撃まわり 693件 passed。
- 本番反映後: 薄い主人公の城からの `order_start` が減り、
  `sortie_held_hero_guard` の取り消しが発生しないことを実測する。
