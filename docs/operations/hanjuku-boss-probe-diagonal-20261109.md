# 半熟英雄: 推定ボスセルの細かい輪に斜めも含める（v546、2026-11-09）

## 背景

v544 で推定ボスセルの探索を「2タイルの細かい輪 → 8タイルの粗い輪」に変えましたが、
細かい輪は**軸方向のみ**（`±16,0` と `0,±16`）でした。推定誤差が斜め1タイル
（x・y 両方に +1）の場合、隣接タイルなのに候補に含まれず当たりません。

## 修正（v546 `hanjuku-chart-v546-boss-probe-diagonal`）

細かい輪を8近傍に拡張しました。

```
(0,0)
(±16,0),(0,±16)          … 軸方向 1〜2タイル
(±16,±16)                … 斜め 1〜2タイル（今回追加）
(±64,0),(0,±64)          … 8タイルの粗い輪（従来どおり）
```

- ローテーションの先頭は従来どおり推定値。未入城の再出撃ごとに次へ進む挙動は不変。
- 第5話（WRAM実測）・第9話（移動ボス）は従来どおり探索しない。
- 候補は13点になりますが、推定が当たれば index 0 のまま、外れた場合も近い輪から順に試します。
