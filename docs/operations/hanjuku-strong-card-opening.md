## 原因

`flows/battle.py` の戦術の並びは「救済の追加札 → 実測した卵落 → それ以外」で、
「それ以外」の中では元の並び順（安定ソート）がそのまま実行順になっていた。
`_tactics` は検証済み戦術の無い携行札へ「開幕に使う」既定の戦術（tactic id `d:`）を
作り、それを検証済み戦術や強い切り札より**前**に並べていたため、強い将軍との戦闘でも
既定の札が先に開いてしまい、強い切り札の出番が無かった。

## 変更

`flows/battle.py` の実行順の序列を明示する。

1. 救済・再攻撃の追加札（`extra`）
2. 実測した卵落（`egg_drop_only`）
3. 検証済みチャート戦術と強い切り札（`strong_only`）
4. 検証済み戦術の無い既定の開幕札（tactic id `d:`）

これで、強い将軍と判定された戦闘では携行した強い切り札が最初に開く。
弱い将軍のときは従来どおり強い切り札を温存し（`_strong_enemy` の判定）、
既定の札が開く。ボス注文の検証済み戦術・卵落の優先・追加札の優先は変えない。
