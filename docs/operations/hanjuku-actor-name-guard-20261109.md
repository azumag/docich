# 半熟英雄: 出撃画面の将軍名が読めれば「しょうぐん」ラベル無しでも通す（v602、2026-11-10）

## 症状（実測・直近1時間）

`sortie_actor_unconfirmed` が **7件**（「代役の出撃画面の本人名を3回で確認できず出撃を取り消す」）。
出撃準備をやり直すため、1時間で7回分の時間が失われていました。

## 原因

`_selected_actor_guard` は出撃画面の y=31 行について

- `span(16, 80)` の**将軍名**が読めること
- `span(80, 128)` が **`しょうぐん`** であること

の両方を要求していました。画面レイアウトの揺れでラベル列が一致しないと、
**名前が正しく読めていても**「未確認」として3回で取り消していました。

## 修正（v602 `hanjuku-chart-v602-actor-name-guard`）

**将軍名そのもの**を強い証拠として扱います。

- 名前が読めて `UNKNOWN` を含まず、参照表にあり、**予定の将軍と一致**していれば、
  ラベル列が一致しなくても**承認**（`named_ok`）。
- 名前が読めない／予定と違う場合は従来どおり保留・取り消し。

## 確認

- `tests/test_hanjuku_sortie_evidence.py` に1件追加（ラベル無しでも名前一致で通る）。
- 出撃・証跡・要求系 189件 passed。
- 本番反映後: `sortie_actor_unconfirmed` が減り、出撃準備のやり直しが減ることを実測する。
