# バルーンフィンチ：実測HPと無測定時の暫定余力によるシャウト（2026-10-16）

2026-10-06の「HP9999まで必ずふくらむ→シャウト」は進行が遅いため、2026-10-16のオーナー指示で更新された。PR #2303は正の被ダメージを実測できた場合に早期シャウトするが、無被弾・カーソル不明時はHP9999まで待つままだった（Issue #2306）。この文書はその再発防止仕様を定める。

## 選択条件

味方のバルーンフィンチ本人が「ふくらむ」「シャウト」の2技を持つ、所有者確定済みの技メニューに限る。シャウトは相手と自分のHPを半減するため、比較対象は使用前HPではなく**シャウト後の自分のHP**。

### 正の被ダメージが実測できた場合

- D = 当該戦闘・相手について観測した最大ターン損失（正数）。
- buffered = ceil(D × 1.25)。
- reserve = max(3 × buffered, 512)。
- **current_hp // 2 が reserve を超えるならシャウト**。不足なら「ふくらむ」。
- 例：D=200ならbuffered=250、reserve=750、目標HP1502。現在HP1800ならシャウト。上限9999で目標を満たせなくても、従来どおり上限時のシャウトを許可する（hp_cap、安全の証明ではない）。

### 敵ダメージがまだ数値化できない場合

**HP9999まで必ず待つという無制限のフォールバックは禁止**する。実際の攻撃を観測できない局面でも進行できるよう、以下の暫定余力を設ける。

| 観測状態 | シャウト前の必要HP | シャウト後の確保HP | ルール名 |
| --- | ---: | ---: | --- |
| 正の損失なし、確定ゼロ損失0〜1回（または入力未確認） | **6144** | 3072以上 | unmeasured_reserve |
| 正の損失なし、確定ゼロ損失2回以上 | **4096** | 2048以上 | observed_zero_reserve |

- いずれも **敵の最大攻撃を3回耐える証明ではない**。未観測の大ダメージ・即死・割合攻撃には保証がない。ログ上は「暫定余力」として実測安全判定 survival_buffer と区別する。
- 低HPでは引き続き「ふくらむ」。HP9999なら従来どおり「シャウト」。戦闘・相手・将軍のscopeがない場合は旧来の上限基準を維持し、根拠不明の早撃ちをしない。
- 実測できる正の損失が現れた時点から暫定目標ではなく、実測3回＋25%＋最低512HPの判定を優先する。

## 被ダメージ／無被弾の観測

- 実カーソルで「ふくらむ」のA確定を返した後、味方HPの**増加**を次の技メニューで確認したときのみ、上限切捨てのない「2 × before_hp − after_hp」を記録する。正値は安全側の最大ターン損失、**0なら確定ゼロ損失1回**として別計数する。上限で回復量が切り捨てられるときはゼロ扱いしない。
- 実カーソルで「シャウト」を選んだ後、after_hp が ceil(before_hp / 2) 以下と観測できた場合、自己HP半減との差を最大2倍して安全側の損失として記録する。自己半減そのものは敵ダメージに含めない。同値なら確定ゼロ損失。未実行／不明なHPでは記録しない。
- 同じ画面の繰り返し、予測カーソル、技を**計画しただけ**の状態ではサンプルを増やさない。回復が未確認・増えないなどの不整合は、過小な旧推定を破棄する。相手・戦闘・将軍の変更、未読HPでも推定を引き継がない。
- 状態は battle.balloon_finch_survival に限定し、旧状態に zero_samples がなくても既存の正の損失を保持できるようにする。

## 記録と検証

既存の monster_menu_choice の observed_metric.balloon_survival に rule、incoming_damage、buffered_damage、survival_hits、post_shout_hp、target_hp、damage_samples、zero_loss_samples を記録する。unmeasured_reserve と observed_zero_reserve が**実測3回生存を保証しない**ことを理由欄にも残す。他の召喚獣・一般退却・卵消費判定は変えない。

対象テスト：

- python -m pytest -q tests/test_hanjuku_balloon_survival.py tests/test_hanjuku_balloon_menu.py
- python -m pytest -q tests/test_hanjuku_chart_bot.py -k 'balloon or monster'

回帰条件は無測定6143/6144境界、ゼロ損失2回による4096境界、実測200の3回耐久、シャウト後の自己HP半減と残余損失の分離、カーソル未読・相手変更・保存復元・上限切捨てを含む。合成画面テストやCI成功は本番の実戦成功や生存保証と同一ではない。

技仕様の参照先：[GCGX カラフルエッグ](https://gcgx.games/hanjuku/colorful_egg.html)（ふくらむ：HP倍増、シャウト：敵味方のHP半減）。
