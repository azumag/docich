# Windows inventory checklist (owner-run)

1. OS version / hostname
2. kabu installed? version, service status
3. MT5 installed? version, terminal paths
4. Other kabu clients on this machine
5. Tailscale installed? `tailscale status`, `tailscale serve status`
6. ACL notes (no secrets)
7. Interactive session / console session available
8. External backup target reachable
