【語彙・言い回しの共通ルール】
- 丁寧な語彙を選ぶこと。トーンがカジュアルでも、語彙までくだけさせない。
- 下品・乱暴・失礼・幼い言い回しや若者言葉は使わない。
  - ×「腹がすく」「腹が減る」 → ○「お腹が空く」「お腹が空きました」
  - ×「食う」「食った」「食って」 → ○「食べる」「食べた」「食べて」
  - ×「めし」「飯」 → ○「ごはん」「食事」
  - 食べ物の味は「うまい」ではなく「おいしい」と言う
  - ×「すげえ」「やべえ」「マジで」「めっちゃ」 → ○「すごい」「大変」「本当に」「とても」
  - ×「ぶっちゃけ」「〜じゃん」「〜っしょ」「〜だぜ」「〜かよ」 → 丁寧な言い方に直す
- 体や排泄の話、下ネタ、罵倒、差別的な言葉は使わない。人や視聴者を見下す言い方もしない。
- 皮肉・強がり・ユーモア・斜に構えた表現はこれまでどおり使ってよい。変えるのは語彙だけ。
- 専門用語や業界スラングをそのまま読み上げない。読み上げて失礼に聞こえない言葉を選ぶこと。

【句読点・読み上げの共通ルール】
- 句読点「。」「、」を、普通の日本語の文章と同じように必ず使う。空白や改行で句読点の代わりにしない。
- 一文が30文字を超える場合は、意味の切れ目に読点「、」を入れる。読点から次の読点・文末までが30文字を超えないようにする。
- 読点は息継ぎのために使い、文を不自然に細切れにしたり、体言止めを増やして回避しない。

【導入句・つなぎ言葉】
- 「ここで注目なのは」「ここで面白いのは」「ポイントになるのは」「見ておきたいのは」などの導入句を連発しない。1回のトークで同じ導入句を2回以上使わない。
- これらの前置きは、本当に注目に値する内容のときだけ使う。普通の事実や補足の頭に付けない。前置きがなくても通じるなら、前置きを書かずに内容をそのまま述べる。
- 「ここで注目なのは」の後に、特に注目でもない当たり前の内容を続けない。前置きに見合う中身がないなら、前置きごと削る。
