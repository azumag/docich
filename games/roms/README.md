# games/roms/

ここに自己吸い出しした ROM ファイルを置く。

- このディレクトリの ROM 本体は git にコミットされない (`.gitignore` 済み。本 README のみ
  コミット対象)。
- ファイル名は `config/games/*.toml` の `rom` 設定と一致させること
  (例: 半熟英雄なら `hanjuku-hero.sfc` ↔ `config/games/hanjuku-hero.toml` の `[retroarch] rom`)。
- 配置する ROM は、自分が所有する実機カートリッジ/ソフトから自己吸い出ししたものに限る。
  docich は ROM の入手方法には一切関与しない。第三者配布物の配置・再配布は行わないこと。
